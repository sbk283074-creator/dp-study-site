B2.4 A recursive implementation of a linear recurrence whose call count is exactly twice the answer minus one, where memoisation changes the cost class and the recursion depth sets a separate, independent limit

Two independent limits are in play and the item is built so that fixing the visible one exposes the hidden one. The visible limit is exponential: the naive recursion calls itself twice per level, so the number of invocations is exactly twice the value being computed minus one, and by nought point two of the way to two thousand that number exceeds ten to the four hundred and seventeen. The hidden limit is the depth of the call stack, which memoisation does nothing whatever about, so the 'fixed' algorithm is fast and still fails.
