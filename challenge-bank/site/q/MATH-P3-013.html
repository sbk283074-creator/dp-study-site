P3 extended problem: the extremum-point shift for e^x = ax and the sum of the two roots

Mathematics: analysis and approaches HL · MATH-P3-013

Topic 5: CalculusSL 5.8 (local maximum and minimum points), SL 5.4 (tangents and normals), AHL 1.6 (simple deductive proof)P315 marksdifficulty 5technology: allowedShow thatProveDetermine

Question

Let $a$ be a real constant and define $h(x) = e^{x} - a x$ for real $x$, so that the equation $e^{x} = ax$ is equivalent to $h(x) = 0$.

  1. [4 marks](a)

    Show that the equation $e^{x} = ax$ has exactly two distinct real roots if and only if $a > e$. State also how many real roots the equation has when $a = e$, when $0 < a < e$, and when $a \le 0$.

    (Show that)
  2. [4 marks](b)

    Now let $a > e$ and write $x_0 = \ln a$. Using the identity $\sinh u = \dfrac{e^{u} - e^{-u}}{2}$, show that for every real $u$
    $$h(x_0 + u) - h(x_0 - u) = 2a\left(\sinh u - u\right),$$
    and hence show that $h(x_0 + u) > h(x_0 - u)$ for every $u > 0$.

    (Show that)
  3. [4 marks](c)

    Let $x_1$ and $x_2$ be the two roots of $h(x) = 0$ with $x_1 < x_2$. Prove that $x_1 + x_2 < 2\ln a$.

    (Prove)
  4. [3 marks](d)

    Taking $a = 4$, determine $x_1$ and $x_2$ correct to four decimal places, and verify that the values you obtain are consistent with the inequality proved in part (c).

    (Determine)

Total: 15 marks. Try the question before revealing anything below.

Let $a$ be a real constant and define $h(x) = e^{x} - a x$ for real $x$, so that the equation $e^{x} = ax$ is equivalent to $h(x) = 0$. (a) Show that the equation $e^{x} = ax$ has exactly two distinct real roots if and only if $a > e$. State also how many real roots the equation has when $a = e$, when $0 < a < e$, and when $a \le 0$. [4 marks] (Show that) (b) Now let $a > e$ and write $x_0 = \ln a$. Using the identity $\sinh u = \dfrac{e^{u} - e^{-u}}{2}$, show that for every real $u$ $$h(x_0 + u) - h(x_0 - u) = 2a\left(\sinh u - u\right),$$ and hence show that $h(x_0 + u) > h(x_0 - u)$ for every $u > 0$. [4 marks] (Show that) (c) Let $x_1$ and $x_2$ be the two roots of $h(x) = 0$ with $x_1 < x_2$. Prove that $x_1 + x_2 < 2\ln a$. [4 marks] (Prove) (d) Taking $a = 4$, determine $x_1$ and $x_2$ correct to four decimal places, and verify that the values you obtain are consistent with the inequality proved in part (c). [3 marks] (Determine)
Reveal the answer

(a) Differentiating gives $h'(x) = e^{x} - a$ (M1).

If $a \le 0$ then $h'(x) = e^{x} - a > 0$ for every real $x$, because $e^{x} > 0$ and $-a \ge 0$; so $h$ is strictly increasing. When $a < 0$, as $x \to -\infty$ we have $e^{x} \to 0$ while $ax \to +\infty$, so $h(x) \to -\infty$; and $h(0) = 1 > 0$. A strictly increasing function that runs from $-\infty$ to a positive value crosses zero exactly once, so there is exactly one real root (A1). If $a = 0$ then $h(x) = e^{x} > 0$ for all $x$, so there is no real root (A1).

If $a > 0$ then $h'(x) = 0$ exactly when $e^{x} = a$, that is at the single point $x_0 = \ln a$; and $h'(x) < 0$ for $x < x_0$, $h'(x) > 0$ for $x > x_0$, so $h$ has a global minimum at $x_0$ (M1). The minimum value is
$$h(x_0) = e^{\ln a} - a\ln a = a - a\ln a = a\left(1 - \ln a\right).$$
If $0 < a < e$ then $\ln a < 1$, so $a(1 - \ln a) > 0$ and the minimum is positive; hence $h(x) > 0$ for all $x$ and there is no real root (A1). If $a = e$ then $\ln a = 1$ and the minimum is exactly $0$, attained only at $x_0 = 1$; so there is exactly one real root, namely $x = 1$ (A1). If $a > e$ then $\ln a > 1$, so $a(1 - \ln a) < 0$; on $(-\infty, x_0]$ the function $h$ decreases strictly from $+\infty$ to this negative value, giving exactly one root there, and on $[x_0, +\infty)$ it increases strictly from that negative value to $+\infty$, giving exactly one further root; these two roots are distinct because $h(x_0) \ne 0$ (A1) (AG). Combining the cases, exactly two distinct real roots occur precisely when $a > e$; one real root occurs when $a = e$ or $a < 0$; and no real root occurs when $0 \le a < e$ (A1).

(b) Expanding the definition,
$$h(x_0+u) - h(x_0-u) = \left(e^{x_0+u} - a(x_0+u)\right) - \left(e^{x_0-u} - a(x_0-u)\right)$$ (M1)
$$= e^{x_0}\left(e^{u} - e^{-u}\right) - 2au.$$
Because $x_0 = \ln a$ we have $e^{x_0} = a$, so the first term is $a\left(e^{u} - e^{-u}\right)$ (A1), and using the given identity $e^{u} - e^{-u} = 2\sinh u$ this becomes
$$h(x_0+u) - h(x_0-u) = 2a\sinh u - 2au = 2a\left(\sinh u - u\right)$$ (A1).
Now let $\varphi(u) = \sinh u - u$. Then $\varphi(0) = 0$ and $\varphi'(u) = \cosh u - 1 \ge 0$ for all real $u$, with equality only at $u = 0$; so $\varphi$ is strictly increasing and $\varphi(u) > 0$ for every $u > 0$ (M1). Since $a > e > 0$, it follows that $2a\varphi(u) > 0$, that is $h(x_0 + u) > h(x_0 - u)$ for every $u > 0$ (A1) (AG).

(c) From part (a) the function $h$ has its global minimum at $x_0 = \ln a$ and exactly two roots, one on each side of $x_0$; hence $x_1 < x_0 < x_2$ (M1). Put $d = x_2 - x_0$, so that $d > 0$ and $x_2 = x_0 + d$. Applying part (b) with $u = d$ gives
$$h(x_0 + d) - h(x_0 - d) = 2a\left(\sinh d - d\right) > 0,$$
and since $h(x_0 + d) = h(x_2) = 0$, it follows that $h(x_0 - d) < 0$ (M1).

On the interval $(-\infty, x_0]$ we have $h'(x) < 0$, so $h$ is strictly decreasing there; both $x_1$ and $x_0 - d$ lie in this interval because $x_1 < x_0$ and $d > 0$ (M1). Because $h$ is strictly decreasing, $h(x_0 - d) < h(x_1)$ forces $x_0 - d > x_1$ (A1). Substituting $d = x_2 - x_0$ gives
$$x_1 < x_0 - \left(x_2 - x_0\right) = 2x_0 - x_2,$$
and rearranging, $x_1 + x_2 < 2x_0 = 2\ln a$, as required (A1) (AG).

(d) Here $x_0 = \ln 4 = 1.3862944$ and $h(x) = e^{x} - 4x$. Solving $e^{x} = 4x$ numerically gives the two roots $x_1 = 0.35740296$ and $x_2 = 2.15329236$ (M1) (A1). Checking: $e^{0.35740296} = 1.42961183$ and $4 \times 0.35740296 = 1.42961183$; $e^{2.15329236} = 8.61316945$ and $4 \times 2.15329236 = 8.61316945$ (A1). The sum is $x_1 + x_2 = 2.51069532$, while $2\ln 4 = 2.77258872$, and indeed $2.51069532 < 2.77258872$, so the inequality of part (c) is satisfied (R1). The margin is about $0.262$, which is far larger than the rounding uncertainty of the four-decimal-place values, so the check is genuine (AG).

Markscheme notes

(a) The differentiation earns (M1) even if the case analysis is incomplete. Full marks require all four cases to be settled, and the two 'no root' cases must be justified, not asserted: for $0 < a < e$ the argument must use $a(1-\ln a) > 0$, and for $a = 0$ the observation $e^{x} > 0$ suffices. Condone the phrase 'the minimum is above the axis' as equivalent to $a(1-\ln a) > 0$. A candidate who claims there is always at least one root because $e^{x}$ eventually beats $ax$ forfeits the final (A1): the whole point of the case $0 < a < e$ is that $e^{x} - ax$ is positive everywhere. Do not accept a graph alone as proof, but a correct graph accompanying a correct sign argument earns full marks.

(b) Award (M1) for separating the two brackets, (A1) for using $e^{x_0} = a$ (not merely $x_0 = \ln a$), (A1) for the closed form $2a(\sinh u - u)$, and (M1) for a valid monotonicity argument for $\sinh u - u$. Candidates may instead differentiate $u \mapsto h(x_0+u) - h(x_0-u)$ directly, obtaining $e^{x_0+u} + e^{x_0-u} - 2a = a(e^{u} + e^{-u}) - 2a = 2a(\cosh u - 1) \ge 0$, and then use the value $0$ at $u = 0$; this is a fully valid alternative and earns all four marks. Follow-through applies: a candidate whose part (a) is wrong but who correctly obtains the difference expression still earns (b).

(c) The essential marks are (M1) for locating the roots on opposite sides of $x_0$, (M1) for using part (b) with $u = x_2 - x_0$ to get $h(x_0-d) < 0$, and (A1) for converting that into a statement about position via the decreasing branch. The reversal of the inequality is the standard error: writing $x_0 - d < x_1$ from $h(x_0-d) < h(x_1)$ on a decreasing branch forfeits the (A1) but the earlier (M1) marks stand. Candidates who instead differentiate $g(u) = h(x_0+u) - h(x_0-u)$ a second time, or who use the convexity of $e^{x}$, may earn full marks if the argument is complete; a proof that the inequality is strict must exclude equality, which happens only in the limiting case $a = e$ that part (a) has already removed.

(d) Award (M1) for setting up the equation and a numerical method, (A1) for both roots to four decimal places, and (R1) only for an actual comparison with the exact value $2\ln 4$, not for a restatement of the roots. Accept a graphical solution or a solver, provided the roots are stated to the required accuracy. A candidate who reports the mirror pair $0.6193$ and $2.4152$ has answered the wrong question: award (M1) for a correct numerical method applied to their own claim, but no (A1), because those values do not satisfy $e^{x} = 4x$; check by substitution.

Why this question is hard

This is the extremum-point-shift problem, the most heavily tested final-question genre in the Chinese national entrance examination's calculus paper. Its whole content is the single observation that the turning point of a two-root function need not be the midpoint of the roots. Everything else is machinery.

The reason the genre is hard is that the false assumption is not algebraically detectable. If you assume the branches are mirror images, you can write a proof that differentiates, finds a positive derivative, and concludes $x_1 + x_2 = 2x_0$ -- and every line of it is locally valid. What is missing is a test. Part (b) supplies the test by asking you to compute the difference between the two branches at equal offset. That difference is not mentioned anywhere in parts (a), (c) or (d); it is a quantity you have to invent. This is why the lever here is the construction of an auxiliary quantity rather than a technique: until you have written down $h(x_0+u) - h(x_0-u)$, you have nothing to test the symmetry hypothesis against.

Once it is written down, the problem becomes easy and, more importantly, becomes checkable. Because $e^{x_0} = a$, the difference collapses to $2a(\sinh u - u)$, and $\sinh u - u$ is the simplest function in the world with value $0$ and derivative $\cosh u - 1 \ge 0$: strictly positive for positive argument. So the right-hand branch sits strictly above the left-hand branch at equal horizontal distance, which means the left root must be further from $x_0$ than the right root is, which is exactly $x_1 + x_2 < 2x_0$.

The final step is the one candidates lose. Having shown $h(x_0 - d) < 0$ and knowing $h(x_1) = 0$, you must convert an inequality between function values into an inequality between arguments -- and because $h$ is *decreasing* on that branch, the inequality reverses. Writing $x_0 - d < x_1$ at that point is the classic error and it turns the proof into a proof of the opposite statement, which is how a candidate can finish with a complete-looking argument and the wrong inequality.

Part (d) exists to make the false answer and the true answer numerically distinguishable. The mirror pair about $\ln 4$ is $0.6193$ and $2.4152$; the true roots are $0.3574$ and $2.1533$. Both sums are close to each other -- $2.7726$ against $2.5107$ -- which is why the error survives a glance at a graph. Substituting back into $e^{x} = 4x$ separates them at once, and a candidate who does not substitute back will not notice.

Challenge lever
The function looks symmetric about its turning point, and every visual cue supports that reading: one turning point, two roots, one on each side. A prepared student therefore sets x = x0 + u on one branch and x = x0 - u on the other, assumes the two branches are mirror images, and obtains x1 + x2 = 2x0 immediately. The whole of the difficulty is that this quantity -- the difference between the two branches at equal offset -- appears nowhere in the question and has to be constructed before it can be used. Once constructed, it collapses to 2a(sinh u - u) and is strictly positive, which proves the opposite inequality. The item is therefore not a trap about algebra but a trap about assuming a symmetry instead of testing it, and the false route is not obviously false: it produces a clean, well-formed proof of a false statement.

Adaptation
The source genre is a single-variable calculus problem in which the two roots of f(x) = 0 straddle a turning point x0, and the student must prove x1 + x2 < 2x0 by constructing the difference of the two branches. Four of the permitted changes were made to fit IB AA HL P3. First, the function was replaced by e^x - ax, chosen because the auxiliary difference h(x0+u) - h(x0-u) then collapses to the exact closed form 2a(sinh u - u) via e^{ln a} = a, which makes the key step checkable rather than merely plausible. Second, a parameter-discussion part was added as (a), asking for the complete classification of the number of real roots; in the source this is normally assumed, and making it explicit is what identifies a = e as the exceptional value. Third, the degenerate case a = e is required explicitly rather than excluded. Fourth, a numerical part (d) was added so that the false symmetric answer and the true answer are separated by a margin a candidate can actually check. The context, the wording and all numerical data are original; nothing is quoted from any source.
Verification
The root count was classified symbolically from the sign of h'(x) and then confirmed numerically by sign-change bisection on a grid of 3,000,001 points over [-60, 60] for a in {-3, -1, -0.001, 0, 0.5, 1, 2, e, 2.72, 3, 4, 10}, giving 1, 1, 1, 0, 0, 0, 0, 0, 2, 2, 2, 2 roots respectively; the double root at a = e was confirmed separately by h(1) = 0 and h'(1) = 0, since a tangency is not a sign change and is invisible to the grid. The identity h(x0+u) - h(x0-u) = 2a(sinh u - u) was verified by expanding both sides and substituting e^{x0} = a. The two roots for a = 4 were located by bisection and substituted back into e^x - 4x, giving residuals below 1e-12; the sum 2.51069532 was compared with 2 ln 4 = 2.77258872 and with the mirror-pair sum, which is identical to 2 ln 4 by construction.
