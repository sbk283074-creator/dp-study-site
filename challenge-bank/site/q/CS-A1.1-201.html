A1.1 Redundancy in a block storage array: the parity block of a stripe is the exclusive OR of that stripe's data blocks, so exactly one lost block per stripe can be rebuilt, and the number of failures tolerated does not grow with the number of disks in the stripe

One stripe of a redundant array of independent disks

A stripe consists of four data blocks followed by one parity block, and the parity block holds the bitwise exclusive OR of the four data blocks of that stripe. Question

The array divides its address space into stripes. A stripe consists of four data blocks and one parity block, and the parity block holds the bitwise exclusive OR of the four data blocks of that stripe. The position of the parity block rotates from stripe to stripe, so that no single disk holds the parity of every stripe. When the array reads a block it reads that block alone; the parity block is consulted only when a block is found to be unreadable. The table gives the four data blocks of one stripe as they were written. The figure shows that stripe together with a neighbouring stripe, and marks one unreadable block in each of the two stripes. The two unreadable blocks are in different stripes, and the controller has not yet had to rebuild two blocks that lie in the same stripe.

  1. [3 marks](a)

    Calculate the parity block of the stripe given in the table, and state the fraction of the array's total block capacity that remains available for data when every stripe carries one parity block for four data blocks.

    (Calculate)
  2. [4 marks](b)

    Show that the value of the block D3 can be rebuilt from the parity block and the three surviving data blocks of the stripe, and determine the value that is rebuilt.

    (Show that)
  3. [3 marks](c)

    Explain why the array can rebuild the two unreadable blocks marked in the figure at the same time, even though it could not rebuild two unreadable blocks that lay in the same stripe.

    (Explain)
  4. [3 marks](d)

    Determine how many simultaneous block failures the array can survive within a single stripe, and state what a second parity block in every stripe would change.

    (Determine)

Reveal the answer

(a) The parity block is the exclusive OR of the four data blocks, so it is computed by combining them two at a time.

0x5A XOR 0x3C = 0x66
0x66 XOR 0xF0 = 0x96
0x96 XOR 0x27 = 0xB1

The parity block is 0xB1. The exclusive OR is associative and commutative, so the order in which the four blocks are combined does not matter.

A stripe that holds four data blocks and one parity block occupies five blocks in order to store four blocks of data. The fraction of the array's capacity available for data is therefore 4/5 = 0.80, that is eighty per cent. The remaining twenty per cent is the cost of the redundancy: one block in every five is spent on the parity and holds no data of its own.

(b) When the block D3 is unreadable, the array knows the parity block 0xB1 and the three surviving data blocks 0x5A, 0x3C and 0x27. The parity block was formed as the exclusive OR of all four data blocks, and the exclusive OR is its own inverse: a value exclusive ORed with itself gives zero, and a value exclusive ORed with zero is unchanged. Combining the parity block with the three surviving blocks therefore cancels those three and leaves the missing one.

0xB1 XOR 0x5A = 0xEB
0xEB XOR 0x3C = 0xD7
0xD7 XOR 0x27 = 0xF0

The rebuilt value is 0xF0, which is the value the table records for D3. The same computation works whichever of the four blocks is lost, because the parity block is symmetric in the four of them; a rebuild of D1 would combine 0xB1 with 0x3C, 0xF0 and 0x27 and return 0x5A.

(c) Each stripe contributes exactly one equation. For the stripe in the table the equation is D1 XOR D2 XOR D3 XOR D4 = P, in which the only unknown is the one block that has been lost, so the equation can be solved. The two unreadable blocks marked in the figure lie in different stripes, so each of the two stripes supplies its own equation, and each of those equations contains one unknown. The two equations are independent of one another, because the stripes are computed separately when the data is written, so they can be solved at the same time and the two blocks can both be rebuilt.

If two blocks of the same stripe were lost, that stripe would supply one equation containing two unknowns, and one equation in two unknowns does not determine either unknown. Every assignment of values to the two missing blocks that keeps the exclusive OR equal to the parity block would satisfy the equation equally well, so the array would have no way to tell which assignment was the original. The stripe's single equation is one constraint, and one constraint removes one unknown.

(d) A stripe with one parity block carries one equation and can therefore absorb exactly one lost block. That number does not depend on how many data blocks the stripe holds: a stripe of four data blocks and a stripe of twelve data blocks each carry one equation and each tolerate exactly one failure. Widening the stripe raises the fraction of the array available for data, since the parity overhead falls from one block in five to one block in thirteen, but it does not raise the tolerance at all. The tolerance is set by the number of parity blocks in the stripe and not by the number of disks in it, which is the point that a candidate who reasons by analogy with the disk count will miss.

A second parity block in every stripe would give each stripe two equations instead of one. Two equations in two unknowns can be solved, so such an array would tolerate two simultaneous block failures within the same stripe, and it would also be able to rebuild a block even when the parity block itself is one of the two failures. The cost is a second block of overhead: a stripe of four data blocks would then occupy six blocks, so the fraction available for data would fall from 4/5 to 4/6, that is from eighty per cent to about sixty-seven per cent.

Markscheme notes

(a) One mark for the method of combining the blocks with the exclusive OR, one mark for the value 0xB1, and one mark for the fraction 4/5 or eighty per cent. A candidate who writes 0xB1 but gives the capacity as five quarters, or as one hundred per cent because the parity is 'not data', forfeits the third mark.

(b) One mark for stating that the exclusive OR is its own inverse or that combining the parity with the survivors cancels them, one mark for a correct sequence of combinations, one mark for the value 0xF0, and one mark for showing the check that the rebuilt value reproduces the parity block. Follow-through is allowed from a wrong parity block in (a) provided the method in (b) is sound, since a candidate who computes 0x00 in (a) and then rebuilds 0xF0 by the correct method has demonstrated the same understanding.

(c) One mark for saying that each stripe supplies its own independent equation, one mark for saying that each of those equations contains one unknown, and one mark for the contrast, that one equation in two unknowns does not determine either unknown. The phrase 'different stripes' alone earns nothing; the reason must be the independence of the equations.

(d) One mark for exactly one failure per stripe, one mark for the statement that this number is independent of the number of data blocks, and one mark for the effect of a second parity block, namely two failures per stripe at the cost of a second block of overhead. An answer that says the tolerance grows with the number of disks scores zero for this part, however well the earlier parts are done.

Why this question is hard

This item is about the difference between a local fact and a property of an aggregate, and the two are separated deliberately. The local fact is that a parity block can be computed and that one lost block can be rebuilt; almost every treatment of RAID gets this far. The aggregate property is that a stripe tolerates one failure no matter how many data blocks it holds, and that the array tolerates as many failures as there are stripes that have lost a block, provided no stripe has lost two.

The four parts walk the candidate from the local to the aggregate. Part (a) is a computation and can be done by anyone who can apply the exclusive OR. Part (b) adds the inverse property, which is the reason the scheme works at all. Part (c) is the first part that cannot be answered by computing anything, because the question is why two failures in different stripes are simultaneously solvable, and the answer is that the stripes are separate systems of equations. Part (d) generalises and asks for the number, which is one, and for the reason, which is that the number of parity blocks and not the number of disks sets the tolerance.

The belief the item is aimed at is common and reasonable-sounding: that a bigger array with more disks is more redundant. It is false in the sense that matters. A twelve-disk array with one parity block per stripe survives exactly as many simultaneous failures within a stripe as a four-disk array does, and in practice it is less safe, because the rebuild of a large array takes longer and the array is at its most vulnerable while it runs. The final part's second half asks for the second parity block, which is the design that does raise the tolerance, and which pays for it with capacity.

The marking is arranged so that the local computation in (a) and (b) cannot carry the item. A candidate can take full marks on those two parts and still score nothing on (d), and that is the intended discrimination.

Challenge lever
The item separates three claims that are usually run together. The first is local: a parity block can be computed, and a single lost block can be rebuilt from it. The second is a claim about the stripe as a whole rather than about any of its blocks, namely that the stripe carries exactly one independent equation and therefore tolerates exactly one lost block, however many data blocks the stripe holds. The third is a claim about the array as a whole rather than about a single stripe, namely that failures in different stripes are independent, so two lost blocks are recoverable precisely when they lie in different stripes. A candidate who has only the first claim will compute the parity block correctly and then answer the last two parts as though redundancy accumulated with the number of disks, which is the belief the item is built to dislodge: adding disks to a stripe adds data and not tolerance.

The rewrite moves the reasoning to a stripe of four data blocks and asks three questions that a local framing cannot answer: whether a specific lost block can be rebuilt, why two lost blocks in different stripes can be rebuilt together while two in the same stripe cannot, and how many failures a stripe tolerates as a function of its width. Verification
Every exclusive OR was evaluated directly. The parity block was formed by combining the four data blocks two at a time and the intermediate values 0x66 and 0x96 were recorded; the parity block was then combined with each of the four data blocks in turn to confirm that the combination returns the block that was omitted, which is the check that the rebuild in part (b) is correct rather than merely plausible. The capacity fractions 4/5 and 4/6 were computed, and the claim that a stripe's tolerance is independent of its width was checked by counting equations rather than by assertion.
