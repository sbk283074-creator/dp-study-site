Rational functions; composite and self-inverse functions

Mathematics: analysis and approaches HL · MATH-T2-001

AHL 2.13 (rational functions of the form (ax + b)/(cx + d)); SL 2.5 (composite functions, identity and inverse functions) — f is self-inverse when f(f(x)) = xP1 · Section B14 marksdifficulty 4technology: not allowedFindHenceShow that

Question

A function $f$ is defined by

$$f(x)=\frac{3x+k}{x-3},\qquad x\neq3,\quad k\in\mathbb{R}.$$

  1. [5 marks](a)

    Find an expression for $f(f(x))$, giving your answer in its simplest form.

    (Find)
  2. [2 marks](b)

    Hence state the set of values of $k$ for which $f$ is self-inverse.

    (Hence)
  3. [3 marks](c)

    Show that when $k=-9$ the function $f$ is not self-inverse, and explain why.

    (Show that)
  4. [4 marks](d)

    Now let $k=7$. Find the coordinates of the points where the graph of $y=f(x)$ intersects the line $y=x$, and hence state what these points show about the graph.

    (Find)

Total: 14 marks. Try the question before revealing anything below.

Reveal the answer

(a) Substitute $f(x)$ into itself:

$$f(f(x))=\frac{3\!\left(\dfrac{3x+k}{x-3}\right)+k}{\dfrac{3x+k}{x-3}-3}$$ (M1)

Multiply numerator and denominator by $(x-3)$:

$$=\frac{3(3x+k)+k(x-3)}{(3x+k)-3(x-3)}$$ (M1)

$$=\frac{9x+3k+kx-3k}{3x+k-3x+9}=\frac{x(9+k)}{k+9}$$ (A1)(A1)

$$f(f(x))=x,\qquad\text{provided }k\neq-9.$$ (A1)

Note the domain condition: the composite is defined only where $f(x)\neq3$, and solving $\dfrac{3x+k}{x-3}\neq3$ again gives $k\neq-9$. So the value that cancels the algebra is the same value that removes the composite's domain.

(b) A function is self-inverse when $f(f(x))=x$ (equivalently $f^{-1}=f$). From (a) this holds for every real $k$ except $k=-9$. (A1)(A1)

So: $f$ is self-inverse for all $k\in\mathbb{R},\ k\neq-9$.

(c) When $k=-9$:

$$f(x)=\frac{3x-9}{x-3}=\frac{3(x-3)}{x-3}=3\qquad(x\neq3)$$ (M1)(A1)

The function is then the constant function $f(x)=3$ on $\mathbb{R}\setminus\{3\}$. It is not one-to-one (every input gives the same output), so no inverse function exists and in particular $f$ is not self-inverse. (R1)

Note that (a) also fails to give $x$ here: $\dfrac{x(9+k)}{k+9}=\dfrac{0}{0}$, which is undefined.

(d) Solve $f(x)=x$:

$$\frac{3x+7}{x-3}=x\ \Rightarrow\ 3x+7=x^{2}-3x\ \Rightarrow\ x^{2}-6x-7=0$$ (M1)

$$\Rightarrow\ (x-7)(x+1)=0\ \Rightarrow\ x=7\ \text{or}\ x=-1$$ (A1)

Check: $f(7)=\dfrac{21+7}{4}=7$ and $f(-1)=\dfrac{-3+7}{-4}=-1$. The points are $(7,\,7)$ and $(-1,-1)$. (A1)

Since $f$ is self-inverse (from (b), with $k=7\neq-9$), the graph of $y=f(x)$ is its own reflection in the line $y=x$; these two points are the fixed points — the points where the graph meets its own axis of symmetry. (R1)

Markscheme notes

(a) Award (M1) for a correct nested substitution even if not yet simplified. The second (M1) is for clearing the compound fraction. Two accuracy marks: one for the correct numerator $x(9+k)$, one for the correct denominator $k+9$. The final (A1) is for stating $f(f(x))=x$ together with the condition $k\ne-9$; a candidate who writes $f(f(x))=x$ with no restriction on $k$ forfeits it.

(b) Requires 'all real $k$ except $-9$'. A bare '$k\neq-9$' is acceptable; 'all values of $k$' without the exception is not.

(c) The final (R1) must say something about one-to-one / many-to-one / no inverse exists. Simply showing $f(x)=3$ earns the first two marks only.

(d) Follow through on a candidate's quadratic. The final (R1) is for the symmetry interpretation — 'they are the fixed points' alone is worth the mark only if linked to the reflection property. In (b) accept the alternative Möbius argument that self-inverse means $a+d=0$ (here $3+(-3)=0$); it earns full credit provided the degenerate value $k=-9$ is still excluded. In (a), a candidate who derives the restriction $k\neq-9$ from the domain of the composite rather than from cancellation has given a stronger answer and should be credited equally.

Why this question is hard

The whole question turns on a piece of algebra that looks as though it should depend on $k$ and does not.

In part (a) the numerator simplifies to $x(9+k)$ and the denominator to $(k+9)$ — the same factor — so $f(f(x))=x$ for every $k$. Students rarely believe this on the first pass: they expect a messy expression and either stop early or make an algebraic slip that reintroduces a spurious $k$-dependence. The point is structural: for any Möbius map $f(x)=\dfrac{ax+b}{cx+d}$, self-inverse is equivalent to $a+d=0$, and here $a+d=3+(-3)=0$ regardless of $k$.

Part (c) is the trap. At $k=-9$ the algebra in (a) collapses to $0/0$, which is exactly the signal that something has gone wrong with the function rather than with the working. The constant function $f(x)=3$ is the degenerate case: it is not one-to-one, so it has no inverse at all — and this is the single value the 'for all $k$' claim must exclude.

Part (d) converts the algebra into geometry. A self-inverse graph is symmetric about $y=x$, so any fixed point must lie *on* that line, and finding them reduces to solving $f(x)=x$.

Classic wrong turns: cancelling $(x-3)$ before clearing the compound denominator; concluding 'self-inverse for all $k$' without testing the degenerate case; and in (d), solving $f(x)=f^{-1}(x)$ (an identity here) instead of $f(x)=x$.

One more classic wrong turn is to treat the domain as incidental. Writing $f(f(x))=x$ for all real $x$ assumes $x=3$ is the only excluded input; the composite is defined only where $f(x)\neq3$, and at $k=-9$ that fails for every $x$, so the composite is empty rather than the identity. A candidate who inverts at $k=-9$ by the swap-and-solve route finds the equation collapse to $x=3$, and may mistake that for an inverse.
