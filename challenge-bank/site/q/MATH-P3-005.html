P3 extended problem: parameter range for an inequality

Mathematics: analysis and approaches HL · MATH-P3-005

Topic 5: CalculusAHL 5.13 (evaluation of limits), AHL 5.14 (implicit differentiation, related rates), SL 5.8 (local maximum and minimum points)P316 marksdifficulty 5technology: not allowedShow thatDetermineHence

Question

Let $a$ be a real constant and let
$$f(x) = x\ln x - a(x-1), \qquad x > 0.$$
The problem is to determine every value of $a$ for which $f(x) \ge 0$ for all $x > 0$.

  1. [4 marks](a)

    Show that $f'(x) = \ln x + 1 - a$, and hence show that $f$ has exactly one stationary point on $x>0$ and that this point is a minimum.

    (Show that)
  2. [5 marks](b)

    Show that the minimum value of $f$ is $a - e^{a-1}$.

    (Show that)
  3. [7 marks](c)

    Determine all values of $a$ for which $f(x) \ge 0$ for all $x > 0$, justifying carefully why no other value works.

    (Determine)

Total: 16 marks. Try the question before revealing anything below.

Let $a$ be a real constant and let $$f(x) = x\ln x - a(x-1), \qquad x > 0.$$ The problem is to determine every value of $a$ for which $f(x) \ge 0$ for all $x > 0$. (a) Show that $f'(x) = \ln x + 1 - a$, and hence show that $f$ has exactly one stationary point on $x>0$ and that this point is a minimum. [4 marks] (Show that) (b) Show that the minimum value of $f$ is $a - e^{a-1}$. [5 marks] (Show that) (c) Determine all values of $a$ for which $f(x) \ge 0$ for all $x > 0$, justifying carefully why no other value works. [7 marks] (Determine)
Reveal the answer

(a) Differentiating, using the product rule on $x\ln x$:
$$f'(x) = \ln x + x\cdot\frac{1}{x} - a = \ln x + 1 - a$$ (M1)(A1)
Setting $f'(x)=0$ gives $\ln x = a-1$, so $x = e^{a-1}$. Since $\ln x$ is strictly increasing on $x>0$, there is exactly one solution for any real $a$, and it is positive, so it lies in the domain. (A1)
$$f''(x) = \frac{1}{x} > 0 \quad \text{for all } x>0$$
so the single stationary point is a minimum. (A1)

(b) At $x = e^{a-1}$ we have $\ln x = a-1$, so (M1)
$$f\bigl(e^{a-1}\bigr) = e^{a-1}(a-1) - a\bigl(e^{a-1}-1\bigr)$$ (A1)
$$= e^{a-1}\bigl[(a-1)-a\bigr] + a$$ (M1)
$$= -e^{a-1} + a = a - e^{a-1}$$ (A1)(AG)

(c) Because $f$ has a single minimum and $f(x)\to\infty$ as $x\to\infty$, the condition $f(x)\ge 0$ for all $x>0$ is equivalent to the minimum being at least zero. (M1) (The left-hand endpoint needs a separate check: as $x\to0^{+}$, $x\ln x\to0$ and $-a(x-1)\to a$, so $f(x)\to a$, and so we also need $a\ge 0$.) (A1)

So we require
$$g(a) = a - e^{a-1} \ge 0.$$
Now treat $g$ as a function of $a$ and maximise it. (M1)
$$g'(a) = 1 - e^{a-1}, \qquad g''(a) = -e^{a-1} < 0$$
so $g'(a) = 0$ at $a = 1$ and this is a maximum. (M1)(A1)
$$g(1) = 1 - e^{0} = 1 - 1 = 0$$
Therefore $g(a) \le 0$ for every real $a$, with equality only at $a=1$. (A1)

Since we need $g(a)\ge 0$ and $g(a)\le 0$ always, the only possibility is $g(a)=0$, which forces $a=1$. This also satisfies the endpoint condition $a\ge0$. (A1)

Answer: $a=1$ is the only value. For this value $f(x) = x\ln x - x + 1 \ge 0$ for all $x>0$, which is the standard inequality $x\ln x \ge x-1$ with equality at $x=1$.

Markscheme notes

(a) The (M1) is for the product rule on $x\ln x$. The uniqueness argument needs the monotonicity of $\ln$, not merely a sketch; award the final (A1) only if $f''>0$ or an equivalent sign argument is given. (b) Follow-through applies from an incorrect stationary point. The subtraction in the second line is where most errors occur: award (M1) for collecting the $e^{a-1}$ terms even if the bracket is wrong. (c) This part is where the question is won. Award (M1) for recognising that a single minimum reduces the condition to one inequality, and a further (A1) for the separate $x\to0^{+}$ check, which is easy to miss because the minimum does not occur at the endpoint. The crucial step is maximising $g$; a candidate who solves $g(a)=0$ numerically and reports $a=1$ without showing it is the only root has not justified uniqueness. Note that $a=1$ also satisfies $a\ge0$, so the endpoint condition is consistent rather than additional. Accept a graphical argument for the maximisation provided the shape of $g$ is established analytically.

Why this question is hard

The structure here is two optimisations in sequence, which is what makes it a Paper 3 problem rather than a Paper 1 one. First the function is minimised over $x$, and the result is not a number but a function of the parameter: the least value of $f$ is $a - e^{a-1}$. Then that function has to be maximised over $a$. Most students stop after the first stage and try to solve $a - e^{a-1} \ge 0$ by inspection or on a calculator, which gives the right answer for the wrong reason and, more importantly, cannot establish that it is the only answer.

The reason uniqueness falls out so cleanly is that $g(a) = a - e^{a-1}$ is concave, with a single maximum of zero at $a=1$. So $g(a)\le 0$ everywhere and touches zero exactly once. The inequality $f(x)\ge0$ for all $x$ therefore has exactly one solution value of the parameter, and for every other value the function dips below the axis somewhere. That is a stronger and more surprising conclusion than the usual 'range of values of $a$' answer, and it is worth being explicit about why: the second optimisation converts an inequality into an equality.

The endpoint check at $x\to0^{+}$ is the part most often omitted. The minimum is interior, so it is tempting to ignore the boundary, but $f(x)\to a$ there, and for negative $a$ the function is negative near zero regardless of what happens at the stationary point. In this instance the final answer survives the check, but only because $a=1\ge0$; a candidate who omits the check has an incomplete argument even though the right answer.

This is a standard shape in the final problem of the Chinese national entrance examination, where a one-parameter family is tested against an inequality on a half-line. The adaptation here keeps the two-stage structure but replaces the usual polynomial family with $x\ln x$, which puts the logarithm and the exponential in the syllabus foreground and makes the second stage analytic rather than requiring a calculator.
