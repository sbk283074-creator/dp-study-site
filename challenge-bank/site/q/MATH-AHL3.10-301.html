3.10 Solving a sin x + b cos x = c by squaring: the quadratic produces one candidate that the unsquared equation never allowed, and the sign condition that rejects it is carried by neither the quadratic nor the final answer list

Mathematics: analysis and approaches HL · MATH-AHL3.10-301

Topic 3: Geometry and trigonometryAHL 3.10 (compound angle identities) with SL 3.8 (solving trigonometric equations in a finite interval)P1 · Section B15 marksdifficulty 4technology: not allowedSolveShow thatExplainDetermine

Question

The equation
$$\sqrt{3}\,\sin x - \cos x = 1$$
is to be solved for $0 \le x \le 2\pi$. Two routes are available. The first writes the left-hand side as a single sine; the second rearranges so that one side can be squared. Note that squaring an equation does not generally produce an equivalent equation, and that the particle whose motion is modelled by this equation is not relevant here.

  1. [3 marks](a)

    Write $\sqrt{3}\sin x - \cos x$ in the form $R\sin(x - \alpha)$ with $R > 0$ and $0 \le \alpha < 2\pi$, giving the exact values of $R$ and $\alpha$. Hence solve the equation.

    (Solve)
  2. [3 marks](b)

    Rearrange the equation into the form $\sqrt{3}\sin x = 1 + \cos x$ and square both sides. Show that the resulting equation reduces to $2\cos^{2}x + \cos x - 1 = 0$, and hence list every value of $x$ in $0 \le x \le 2\pi$ suggested by the quadratic.

    (Show that)
  3. [4 marks](c)

    One of the values listed in part (b) is not a solution of the original equation. Identify it, verify by direct substitution that it fails, and explain, in terms of the sign forced on $\sin x$ by the rearranged but unsquared equation, why squaring admitted it and why the other admissible value it also produces survives.

    (Explain)
  4. [3 marks](d)

    The equation is now changed to $\sqrt{3}\sin x - \cos x = -1$. Determine all solutions in $0 \le x \le 2\pi$ by either route, determine which candidate the squaring route generates that has to be rejected, and state the sign condition that rejects it.

    (Determine)
  5. [2 marks](e)

    Explain why the squaring route can generate extra solutions but can never lose one, and hence state precisely what must be done to every value it produces before it can be reported as a solution.

    (Explain)

Total: 15 marks. Try the question before revealing anything below.

Reveal the answer

(a) Matching coefficients in $R\sin(x - \alpha) = R\sin x\cos\alpha - R\cos x \sin\alpha$ against $\sqrt{3}\sin x - \cos x$ requires
$$R\cos\alpha = \sqrt{3} \quad\text{and}\quad R\sin\alpha = 1 \;(M1),$$
so $R = \sqrt{3 + 1} = 2$ and $\tan\alpha = \tfrac{1}{\sqrt{3}}$ with both $\cos\alpha$ and $\sin\alpha$ positive, giving
$$R = 2, \quad \alpha = \tfrac{\pi}{6} \;(A1).$$
The equation becomes $2\sin\bigl(x - \tfrac{\pi}{6}\bigr) = 1$, that is $\sin\bigl(x - \tfrac{\pi}{6}\bigr) = \tfrac{1}{2}$. With $0 \le x \le 2\pi$ we have $-\tfrac{\pi}{6} \le x - \tfrac{\pi}{6} \le \tfrac{11\pi}{6}$, so
$$x - \tfrac{\pi}{6} = \tfrac{\pi}{6} \quad\text{or}\quad x - \tfrac{\pi}{6} = \tfrac{5\pi}{6} ,$$
giving $x = \tfrac{\pi}{3}$ or $x = \pi$ (A1). Checking: at $x = \tfrac{\pi}{3}$, $\sqrt{3}\cdot\tfrac{\sqrt{3}}{2} - \tfrac{1}{2} = \tfrac{3}{2} - \tfrac{1}{2} = 1$; at $x = \pi$, $\sqrt{3}\cdot 0 - (-1) = 1$. Both work.
(b) Rearranging gives $\sqrt{3}\sin x = 1 + \cos x$ (M1). Squaring,
$$3\sin^{2}x = (1 + \cos x)^{2} = 1 + 2\cos x + \cos^{2}x ,$$
and using $\sin^{2}x = 1 - \cos^{2}x$,
$$3 - 3\cos^{2}x = 1 + 2\cos x + \cos^{2}x \;\Longrightarrow\; 4\cos^{2}x + 2\cos x - 2 = 0 \;\Longrightarrow\; 2\cos^{2}x + \cos x - 1 = 0 \;(A1),$$
as required. Factorising, $(2\cos x - 1)(\cos x + 1) = 0$, so $\cos x = \tfrac{1}{2}$ or $\cos x = -1$. In $0 \le x \le 2\pi$ these give
$$x = \tfrac{\pi}{3}, \; \tfrac{5\pi}{3} \quad\text{and}\quad x = \pi \;(A1),$$
three candidate values where part (a) found only two solutions.
(c) Substituting $x = \tfrac{5\pi}{3}$ into the left-hand side,
$$\sqrt{3}\,\sin\tfrac{5\pi}{3} - \cos\tfrac{5\pi}{3} = \sqrt{3}\Bigl(-\tfrac{\sqrt{3}}{2}\Bigr) - \tfrac{1}{2} = -\tfrac{3}{2} - \tfrac{1}{2} = -2 \neq 1 \;(A1),$$
so $x = \tfrac{5\pi}{3}$ is not a solution and must be rejected (A1). The reason is visible in the unsquared rearrangement $\sqrt{3}\sin x = 1 + \cos x$: since $\cos x \ge -1$, the right-hand side satisfies $1 + \cos x \ge 0$ for every $x$, and therefore any genuine solution must satisfy $\sin x \ge 0$ (M1). Squaring replaced the equation $\sqrt{3}\sin x = 1 + \cos x$ by $3\sin^{2}x = (1 + \cos x)^{2}$, which is equally satisfied when $\sqrt{3}\sin x = -(1 + \cos x)$, so it retains solutions of the equation with the opposite sign that the original never possessed. At $x = \tfrac{5\pi}{3}$ we have $\sin x = -\tfrac{\sqrt{3}}{2} < 0$, so it is precisely a solution of the sign-reversed equation and fails the condition (A1). The other value produced by the same factor, $x = \tfrac{\pi}{3}$, has $\sin x = \tfrac{\sqrt{3}}{2} > 0$ and survives, as does $x = \pi$ from the other factor, which has $\sin x = 0$ and so satisfies $1 + \cos x = 0$ with both sides zero.
(d) Using the form from part (a), $2\sin\bigl(x - \tfrac{\pi}{6}\bigr) = -1$, so $\sin\bigl(x - \tfrac{\pi}{6}\bigr) = -\tfrac{1}{2}$. In the interval $-\tfrac{\pi}{6} \le x - \tfrac{\pi}{6} \le \tfrac{11\pi}{6}$ this occurs when $x - \tfrac{\pi}{6} = -\tfrac{\pi}{6},\; \tfrac{7\pi}{6}$ or $\tfrac{11\pi}{6}$, hence
$$x = 0, \quad x = \tfrac{4\pi}{3}, \quad x = 2\pi \;(M1)(A1).$$
Checking: $x = 0$ gives $0 - 1 = -1$; $x = \tfrac{4\pi}{3}$ gives $\sqrt{3}\bigl(-\tfrac{\sqrt{3}}{2}\bigr) - \bigl(-\tfrac{1}{2}\bigr) = -\tfrac{3}{2} + \tfrac{1}{2} = -1$; $x = 2\pi$ gives $0 - 1 = -1$. The squaring route here rearranges to $\sqrt{3}\sin x = \cos x - 1$, then squares to $3\sin^{2}x = (\cos x - 1)^{2}$, giving $3 - 3\cos^{2}x = \cos^{2}x - 2\cos x + 1$, that is $2\cos^{2}x - \cos x - 1 = 0$, so $\cos x = -\tfrac{1}{2}$ or $\cos x = 1$ and the candidates are $x = \tfrac{2\pi}{3},\; \tfrac{4\pi}{3},\; 0,\; 2\pi$. The rejected one is
$$x = \tfrac{2\pi}{3}, \quad\text{since}\quad \sqrt{3}\sin\tfrac{2\pi}{3} - \cos\tfrac{2\pi}{3} = \tfrac{3}{2} + \tfrac{1}{2} = 2 \neq -1 \;(A1),$$
and the condition that rejects it is $\sin x \le 0$, forced by the rearrangement $\sqrt{3}\sin x = \cos x - 1$ whose right-hand side cannot be positive. Indeed $\sin\tfrac{2\pi}{3} = \tfrac{\sqrt{3}}{2} > 0$.
(e) Squaring replaces $P = Q$ by $P^{2} = Q^{2}$, and every solution of $P = Q$ does satisfy $P^{2} = Q^{2}$, so no genuine solution can be lost (M1). The converse fails: $P^{2} = Q^{2}$ is equivalent to $P = Q$ or $P = -Q$, so the squared equation generally admits solutions of $P = -Q$ as well. Each value the route produces must therefore be substituted back into the original equation, or equivalently checked against whatever sign condition the rearrangement forces, before it is reported (A1).

Markscheme notes

(a) (M1) for setting up the two equations $R\cos\alpha = \sqrt{3}$ and $R\sin\alpha = 1$, (A1) for $R = 2$ and $\alpha = \tfrac{\pi}{6}$ together, with the quadrant justified or evident from the signs, (A1) for both solutions $\tfrac{\pi}{3}$ and $\pi$. Accept answers in degrees if consistently converted. Do not accept $\alpha = \tfrac{\pi}{6}$ obtained from $\tan\alpha = \tfrac{1}{\sqrt{3}}$ alone without establishing the quadrant; $\alpha = \tfrac{7\pi}{6}$ satisfies the tangent equation but gives $R\sin(x - \alpha)$ with the wrong signs.
(b) (M1) for the rearrangement, (A1) for reaching $2\cos^{2}x + \cos x - 1 = 0$ using the Pythagorean identity, (A1) for the complete list of three candidates. Follow-through applies throughout: a candidate whose quadratic differs but whose list is consistent with it keeps the later marks in parts (c) and (d). Forfeits: omitting $\tfrac{5\pi}{3}$ from the list, which removes the entire point of the question and loses this mark and every mark in part (c) that depends on identifying a spurious value.
(c) (A1) for identifying $x = \tfrac{5\pi}{3}$ and computing the left-hand side as $-2$, (A1) for stating that it is rejected, (M1) for observing that the rearrangement forces $1 + \cos x \ge 0$ and therefore $\sin x \ge 0$, (A1) for connecting that to the two surviving candidates and to failure at $\tfrac{5\pi}{3}$. The substitution is required, not optional: a candidate who merely asserts 'the fifth pi over three does not work' scores (A1) for identification only. Do not accept 'it is outside the range' as a reason, since it is plainly inside $0 \le x \le 2\pi$.
(d) (M1) for applying either route correctly to the new right-hand side, (A1) for all three solutions $0$, $\tfrac{4\pi}{3}$ and $2\pi$, (A1) for identifying $\tfrac{2\pi}{3}$ as the rejected candidate with the arithmetic $-2$ replaced by $2 \neq -1$, together with the condition $\sin x \le 0$. Note the symmetry with part (c): the rejected value is the one whose sine has the wrong sign for the rearrangement in force, and the sign is the opposite of the part (c) condition. Condone a candidate who lists $2\pi$ as $0$ redundantly, provided no solution is omitted, and condone omission of one endpoint if the other two are correct and the reasoning is otherwise sound.
(e) (M1) for the observation that solutions may be gained but cannot be lost, (A1) for the requirement that every candidate be checked in the original equation or against the forced sign condition. Accept either formulation as equivalent.

Why this question is hard

This item is about ownership of an inequality. When the equation is written as $\sqrt{3}\sin x - \cos x = 1$ nothing announces that a sign is being carried. When it is written as $\sqrt{3}\sin x = 1 + \cos x$ the right-hand side is manifestly non-negative, and that is the whole content of the condition that later rejects $\tfrac{5\pi}{3}$. The condition is not invented to patch the method; it is already true in the original equation and merely invisible in that arrangement.

The reason this is worth an item rather than a footnote is that every part of the squaring route looks successful. The rearrangement is exact, the use of $\sin^{2}x = 1 - \cos^{2}x$ is standard, the quadratic factorises cleanly into $(2\cos x - 1)(\cos x + 1)$, and each factor yields recognisable special-angle values. There is no step at which an error is visible. Three candidates come out against two real solutions, and the only way to notice is to compare against a second route or to substitute back. Part (a) exists to supply exactly that second route, and it is worth remarking that the $R\sin(x - \alpha)$ form can do no such violence, because taking a sine of an angle never introduces a sign ambiguity in the reverse direction.

Part (d) is not repetition. It flips the right-hand side to $-1$, which flips the forced condition to $\sin x \le 0$, and it flips which member of the pair of candidates is rejected -- now $\tfrac{2\pi}{3}$ rather than $\tfrac{5\pi}{3}$. A candidate who learned a rule about 'the third-quadrant value is always spurious' has learned nothing transferable, and part (d) is designed to expose that immediately. It also has three genuine solutions rather than two, which quietly demolishes the common belief that equations of this shape always have exactly two solutions on the interval; whether the endpoints count depends on where the curve sits, and here both $0$ and $2\pi$ are genuine.

The general lesson in part (e) is worth holding precisely: squaring is a one-way implication. $P = Q$ implies $P^{2} = Q^{2}$ but not conversely, because $P^{2} = Q^{2}$ encodes the disjunction $P = \pm Q$. Nothing is ever lost, and whatever is gained must be paid for by substitution. That asymmetry is why the route can be used freely as a generator of candidates and can never be trusted as a deliverer of solutions.

Challenge lever
Squaring a trigonometric equation is a legitimate move and the resulting quadratic in $\cos x$ factorises beautifully, which makes the whole route feel trustworthy. What the route silently destroys is the sign information in the unsquared equation: $\sqrt{3}\sin x = 1 + \cos x$ forces $\sin x \ge 0$ because the right-hand side cannot be negative, and that single inequality is the only thing separating the two genuine solutions from the spurious third. The discarded condition is nowhere in the quadratic, nowhere in its roots, and is recovered only by going back to the equation before it was squared.

The source genre uses the auxiliary-angle form to reach a single-sine equation and then solves it; squaring appears only incidentally, if at all, and the loss of sign information is treated as a warning in a margin. Here squaring is promoted to being the main route in part (b) and is made to fail visibly, the sign condition is derived rather than quoted, and part (d) changes the right-hand side so that the condition reverses -- producing a different rejected value and thereby testing whether the reasoning transferred. Verification
