Maximising the volume of an open-topped box folded from a square sheet, and recognising that the outer surface area has no maximum inside the domain

Question

A square sheet of card of side $12$ cm is used to make an open-topped box. A square of side $x$ cm is cut from each corner and the sides are folded up along the dashed lines, as shown in the diagram.

  1. [3 marks](a)

    Show that the volume of the box is $V = x(12 - 2x)^{2}$ and state the domain of the function $V$.

    (Show that)
  2. [5 marks](b)

    Find $\dfrac{dV}{dx}$ and hence show that $V$ has a maximum value when $x = 2$.

    (Find)
  3. [2 marks](c)

    Find the maximum volume of the box, giving your answer in cubic centimetres.

    (Find)
  4. [4 marks](d)

    A designer suggests choosing $x$ so that the outer surface area $S$ of the box is as large as possible. Show that $S = 144 - 4x^{2}$, and explain why no value of $x$ in the domain maximises $S$.

    (Show that)

(a) Show that the volume of the box is $V = x(12 - 2x)^{2}$ and state the domain of the function $V$. [3 marks] (Show that) (b) Find $\dfrac{dV}{dx}$ and hence show that $V$ has a maximum value when $x = 2$. [5 marks] (Find) (c) Find the maximum volume of the box, giving your answer in cubic centimetres. [2 marks] (Find) (d) A designer suggests choosing $x$ so that the outer surface area $S$ of the box is as large as possible. Show that $S = 144 - 4x^{2}$, and explain why no value of $x$ in the domain maximises $S$. [4 marks] (Show that)
Reveal the answer

(a) Cutting a square of side $x$ from each corner removes $x$ from both ends of
each side of the sheet, so the base of the box is a square of side

$$12 - 2x.$$ (M1)

Folding the sides up gives a box whose height is $x$, so its volume is the area of the base
multiplied by the height:

$$V = (12 - 2x)^{2} \cdot x = x(12 - 2x)^{2}.$$ (A1)(AG)

For the box to exist the base must have a positive side, so $12 - 2x > 0$, which gives
$x < 6$; and the height must be positive, so $x > 0$. The domain is therefore

$$0 < x < 6.$$ (A1)

Both endpoints are excluded, because at $x = 0$ there is no box to fold and at $x = 6$ the base
has zero area.

(b) Expanding first makes the differentiation straightforward:

$$V = x(12 - 2x)^{2} = x\left( 144 - 48x + 4x^{2} \right) = 4x^{3} - 48x^{2} + 144x.$$

Differentiating,

$$\frac{dV}{dx} = 12x^{2} - 96x + 144 = 12\left( x^{2} - 8x + 12 \right) = 12(x - 2)(x - 6).$$ (M1)(A1)

Setting $\dfrac{dV}{dx} = 0$ gives $x = 2$ or $x = 6$. (A1)

The root $x = 6$ is excluded because it lies outside the domain $0 < x < 6$; it is the value at
which the base has collapsed to a point and the volume is zero. (R1)

To classify $x = 2$, differentiate again:

$$\frac{d^{2}V}{dx^{2}} = 24x - 96, \qquad
\left. \frac{d^{2}V}{dx^{2}} \right|_{x=2} = 48 - 96 = -48 < 0.$$ (A1)

A negative second derivative means the stationary point is a maximum, so $V$ is a maximum at
$x = 2$. (AG)

(c) Substituting $x = 2$ into the volume:

$$V = 2\left( 12 - 2(2) \right)^{2} = 2(8)^{2} = 2(64) = 128.$$ (M1)(A1)

The maximum volume is $128$ cm$^{3}$.

(d) The outer surface area of the open-topped box consists of the square base and the four
rectangular sides. The base has area $(12 - 2x)^{2}$, and each side has area $x(12 - 2x)$, so

$$S = (12 - 2x)^{2} + 4x(12 - 2x).$$ (M1)

Taking out the common factor $(12 - 2x)$:

$$S = (12 - 2x)\left[ (12 - 2x) + 4x \right] = (12 - 2x)(12 + 2x).$$ (A1)

This is a difference of two squares:

$$S = 144 - 4x^{2}.$$ (A1)(AG)

The derivative is

$$\frac{dS}{dx} = -8x,$$

which is strictly negative for every $x$ in the domain $0 < x < 6$, since $x$ is positive
there. The function $S$ is therefore strictly decreasing throughout the domain and has no
stationary point inside it. (A1)

Consequently there is no value of $x$ in $(0, 6)$ at which $S$ takes its maximum. The largest
value is approached as $x$ tends to $0$ from above, where $S$ tends to $144$, but that value is
never attained: at $x = 0$ there is no box, only an uncut sheet. So the designer's suggestion
cannot be carried out — the surface area can be made as close to $144$ cm$^{2}$ as desired but
never actually maximised.

Markscheme notes

(a) (M1) for identifying the base as a square of side $12 - 2x$, (A1) for the volume expression, (AG) for the stated result, (A1) for the domain $0 < x < 6$. The domain must exclude both endpoints; a domain of $0 \leq x \leq 6$ scores (A0). (b) (M1) for differentiating, (A1) for $12x^{2} - 96x + 144$ or the factorised form $12(x - 2)(x - 6)$, (A1) for both roots, (R1) for rejecting $x = 6$ with reference to the domain, (A1) for the second derivative and the conclusion that $x = 2$ is a maximum. Award (R1) only if the reason given is the domain or the collapse of the base; merely discarding the root without a reason scores (R0). (c) (M1) for substituting $x = 2$, (A1) for $128$ with units. (d) (M1) for forming the surface area as base plus four sides, (A1) for the common-factor step, (A1) for $144 - 4x^{2}$, (AG) for the stated result, (A1) for showing $dS/dx = -8x < 0$ on the domain and concluding that no maximum is attained. The final mark requires the explicit conclusion about non-attainment; a statement that $S$ is decreasing alone scores (A0) for that mark.

Why this question is hard

This is an optimisation item with a boundary that binds, and the boundary is the
whole point. The volume function has two stationary points and the domain excludes one of them,
which means the standard routine of setting the derivative to zero and accepting every root
produces an answer that cannot be right. The domain is stated in part (a) precisely so that it
can be used in part (b), and a student who carries it past without checking will report two
candidate values for the maximum when only one of them is admissible. The second derivative
test is then needed to confirm that the surviving root is a maximum rather than a minimum, and
that is the part the item asks to be shown rather than asserted.

The factorisation of the derivative is worth doing rather than leaving in expanded form, because
the roots are then visible immediately as x = 2 and x = 6. The root at x = 6 is not a
distractor invented for the exercise: it is the value at which the base of the box has zero
area, so the volume is genuinely zero there, and it sits exactly at the endpoint of the domain.
That is why the domain has to exclude it.

Part (d) is the part that lifts the item above a routine exercise. The surface area turns out to
be 144 - 4x^2, which is a downward parabola in x with its vertex at x = 0, outside the domain.
On the open interval (0, 6) the function is strictly decreasing, so the largest value is
approached at the left-hand end and never reached. A box of zero height is not a box, so there
is no admissible value of x that achieves the maximum. The honest answer is that no such x
exists, and the item asks for that conclusion explicitly because it is the step a student is
most likely to skip: the habit built by every previous optimisation question is that a maximum
exists and is found by setting a derivative to zero, and here that habit produces nothing.

There is a second point in part (d) worth noticing. The two design goals, maximising volume and
maximising surface area, give answers at opposite ends of the domain: the volume is largest at
x = 2, in the interior, while the surface area is largest as x approaches 0. The two objectives
are in tension, and that is a genuine design observation rather than an artefact of the
algebra. The item stops short of asking which goal is preferable, because that is a judgement
rather than a calculation, but the tension is visible in the two answers and is worth pointing
out.

Challenge lever
The volume function has two stationary points, at x = 2 and at x = 6, and only the first lies in the domain 0 < x < 6. The first move a prepared student makes is to set dV/dx = 0, solve the resulting quadratic and accept both roots as candidate answers, because the domain is stated in the question and is easy to carry past without checking. The second demand is the last part, where the surface area turns out to be S = 144 - 4x^2, which is strictly decreasing on the whole domain. There is therefore no value of x in (0, 6) that maximises S: the largest value is approached as x tends to zero and is never attained, because a box of zero height is not a box. Recognising that a maximum can fail to exist on an open interval is the idea that separates this item from a routine optimisation exercise, where a maximum is always assumed to exist at a stationary point.
