A composite function that loses one point and one value

Mathematics: analysis and approaches HL · MATH-AHL2.2-001

SL 2.2 (concept of a function, domain, range and graph) and SL 2.3 (the graph of a function; its equation y = f(x))P1 · Section B15 marksdifficulty 4technology: not allowedStateFindDetermineExplain

Question

The functions $f$ and $g$ are defined by $f(x) = \sqrt{x + 5}$ and $g(x) = \frac{x^2 - 9}{x - 3}$.

  1. [3 marks](a)

    State the largest possible domain of $f$ and the corresponding range of $f$.

    (State)
  2. [4 marks](b)

    Find the inverse function $f^{-1}$, stating its domain and its range.

    (Find)
  3. [5 marks](c)

    Determine the largest possible domain of the composite function $g \circ f$, and simplify $(g \circ f)(x)$.

    (Determine)
  4. [3 marks](d)

    Explain why the range of $g \circ f$ is not the interval $[3, \infty)$, and state the value that is missing.

    (Explain)

Total: 15 marks. Try the question before revealing anything below.

Reveal the answer

(a) The expression $\sqrt{x+5}$ is defined when the radicand is non-negative, so $x + 5 \ge 0$, that is $x \ge -5$. (A1) The largest possible domain is therefore $[-5, \infty)$. (A1) The endpoint $-5$ is included because the radicand is exactly zero there. A square root takes only non-negative values, and as $x$ runs over the domain the value $\sqrt{x+5}$ covers every non-negative number, so the range is $[0, \infty)$. (A1)

(b) Setting $y = \sqrt{x+5}$ and squaring gives $y^2 = x + 5$, so $x = y^2 - 5$. (M1) Interchanging $x$ and $y$, $f^{-1}(x) = x^2 - 5$. (A1) The domain of $f^{-1}$ is the range of $f$, namely $x \ge 0$. (A1) The range of $f^{-1}$ is the domain of $f$, namely $y \ge -5$. (A1)

(c) For $x$ in the domain of $f$, $(g \circ f)(x) = \frac{(f(x))^2 - 9}{f(x) - 3} = \frac{(f(x)-3)(f(x)+3)}{f(x)-3} = f(x) + 3 = \sqrt{x+5} + 3$. (M1) This simplification requires $f(x) \ne 3$. (R1) Now $\sqrt{x+5} = 3$ exactly when $x + 5 = 9$, that is $x = 4$. (A1) The value $x = 4$ lies in the domain of $f$ but must be removed from the domain of $g \circ f$. (A1) Hence the largest possible domain is $[-5, 4) \cup (4, \infty)$. (A1)

(d) As $x$ runs over $[-5, \infty)$, the expression $\sqrt{x+5} + 3$ takes every value from $3$ upwards, so the naive range is $[3, \infty)$. (R1) However, $x = 4$ has been excluded from the domain, and at $x = 4$ the composite would take the value $\sqrt{9} + 3 = 6$. (A1) That single value is therefore missing, and the range is $[3, 6) \cup (6, \infty)$. (A1) The value $6$ is approached as $x$ approaches $4$ from either side, so it is a single isolated gap rather than an interval of missing values.

Markscheme notes

Part (a) awards three (A1) marks, one for the domain $x \ge -5$, one for writing it as $[-5, \infty)$, and one for the range $[0, \infty)$; the range mark requires the candidate to note that a square root is non-negative. In part (b) the (M1) is for squaring and rearranging to $x = y^2 - 5$, and the (A1) is for $f^{-1}(x) = x^2 - 5$. The remaining two (A1) marks are for the domain $x \ge 0$ and the range $y \ge -5$ of the inverse, which come from swapping the domain and range of $f$; a candidate who writes $x \ge -5$ for the inverse has not swapped them and loses that mark. Part (c) awards (M1) for the algebraic simplification to $\sqrt{x+5} + 3$ and (R1) for stating that this requires $f(x) \ne 3$. The (A1) marks are for solving $\sqrt{x+5} = 3$ to get $x = 4$, for recognising that $4$ lies in the domain of $f$ but not of the composite, and for the final domain $[-5, 4) \cup (4, \infty)$. Part (d) awards (R1) for the naive range $[3, \infty)$ and (A1) for the excluded value $6$; the final (A1) is for the range $[3, 6) \cup (6, \infty)$. A candidate who omits the missing value cannot earn the last two marks.

Why this question is hard

The two functions are individually simple, and the difficulty comes from the single point at which the composite loses meaning. Part (a) fixes the domain and range of $f$, and part (b) forces the candidate to remember that the inverse function exchanges them: the domain of $f^{-1}$ is $[0, \infty)$ and its range is $[-5, \infty)$, not the other way round. This swap is the standard trap, and it matters later because it determines which values the composite can produce.

Part (c) is the core of the item. The quotient $((f(x))^2 - 9)/(f(x) - 3)$ simplifies to $f(x) + 3$ only where $f(x) \ne 3$, and $f(x) = 3$ precisely at $x = 4$. The cancellation is legitimate algebra but it removes a genuine hole, so the largest domain of $g \circ f$ is $[-5, \infty)$ with $4$ deleted. A candidate who cancels without recording the exclusion has quietly changed the function.

Part (d) makes that hole visible. The simplified expression $\sqrt{x+5} + 3$ would sweep out $[3, \infty)$, but the excluded input $x = 4$ would have produced exactly $6$, so $6$ alone is missing. The range is therefore $[3, 6) \cup (6, \infty)$. This is the point of the question: an algebraic simplification can hide a single deleted value, and only tracking the domain reveals it. A second subtlety is that the domain of the composite is not the whole domain of $f$: because $g$ is undefined at its own denominator zero, the input that makes $f(x) = 3$ must be removed, and this removal is invisible once the fraction has been cancelled. Candidates who work only with the simplified expression $\sqrt{x+5} + 3$ will state a range that is too large. Checking a value just below and just above $x = 4$ confirms that the composite approaches $6$ from both sides but never attains it.
