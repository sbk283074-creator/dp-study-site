The root that survives only because the index is odd

Mathematics: analysis and approaches HL · MATH-AHL1.7-001

SL 1.7 (laws of exponents with rational exponents) and SL 1.5 (laws of exponents with integer exponents)P1 · Section B15 marksdifficulty 4technology: not allowedExplainShow thatHence

Question

Consider the equation $(x+1)^{2/3} - 3(x+1)^{1/3} - 4 = 0$, where the powers are interpreted as real powers of the base.

  1. [3 marks](a)

    Explain why $x^{1/3}$ is defined for every real $x$ but $x^{1/2}$ is not, and state the values of $x$ for which the left-hand side is defined.

    (Explain)
  2. [4 marks](b)

    Show that substituting $t = (x+1)^{1/3}$ gives the quadratic $t^{2} - 3t - 4 = 0$, and hence find the two possible values of $t$.

    (Show that)
  3. [5 marks](c)

    Hence find all real solutions of the original equation, checking that each value you obtain is valid.

    (Hence)
  4. [3 marks](d)

    Explain how a student solving $(x+1)^{1/2} - 3(x+1)^{1/4} - 4 = 0$ in the same way obtains two values of $x$, and explain why one of them must be rejected.

    (Explain)

Total: 15 marks. Try the question before revealing anything below.

Reveal the answer

(a) A cube root of a negative number is real, because $(-2)^{3} = -8$, so $x^{1/3}$ is defined for every real $x$. (M1) A square root of a negative number is not real, so $x^{1/2}$ is defined only for $x \ge 0$. (A1) Since the expression contains only the cube-root power, it is defined for every real $x$. (A1)

(b) Substituting $t = (x+1)^{1/3}$ gives $t^{2} - 3t - 4 = 0$. (M1) Factorising, $(t - 4)(t + 1) = 0$. (M1) Hence $t = 4$ or $t = -1$. (A1) Both values are permitted because $t$ is a cube root and may be negative. (R1)

(c) From $t = 4$, $x + 1 = 4^{3} = 64$, so $x = 63$. (M1)(A1) From $t = -1$, $x + 1 = (-1)^{3} = -1$, so $x = -2$. (M1)(A1) Both are valid because the cube root of a negative number is real. (R1) Checking, at $x = 63$ the left-hand side is $64^{2/3} - 3 \times 64^{1/3} - 4 = 16 - 12 - 4 = 0$, and at $x = -2$ it is $1 - 3(-1) - 4 = 0$. (A1)

(d) With $t = (x+1)^{1/4}$ the same quadratic gives $t = 4$ or $t = -1$. (M1) From $t = 4$, $x + 1 = 4^{4} = 256$, so $x = 255$; from $t = -1$, $x + 1 = (-1)^{4} = 1$, so $x = 0$. (A1) A fourth root is defined to be non-negative, so $t = -1$ is impossible and $x = 0$ must be rejected, leaving only $x = 255$. (R1)

Markscheme notes

Part (a): the (M1) is for the cube root of a negative number being real, with the example $(-2)^{3} = -8$ earning the credit; the first (A1) is for restricting $x^{1/2}$ to $x \ge 0$ and the second for concluding that the expression is defined for all real $x$. A candidate who claims the cube root is undefined for negative $x$ loses both (A1) marks. Part (b): the two (M1) marks are for the substitution and the factorisation, the (A1) for the two roots, and the (R1) for observing that both roots are admissible for a cube root. Part (c): the (M1)(A1) pairs are for cubing each value of $t$ and for the resulting $x$. The (R1) is for justifying that the negative root gives a real solution, and the final (A1) is for the substitution check. A candidate who rejects $x = -2$ on the grounds that the base is negative has confused the cube root with the square root and forfeits the (R1) and the final (A1). Part (d): the (M1) is for applying the same quadratic, the (A1) for the two candidate values $x = 255$ and $x = 0$, and the (R1) for rejecting $x = 0$ because a fourth root is non-negative. Accept a justification phrased as $t \ge 0$ by definition of the principal root.

Why this question is hard

The substitution $t = (x+1)^{1/3}$ collapses the equation to the quadratic $t^{2} - 3t - 4 = 0$, whose roots are $4$ and $-1$. The algebra is short; the difficulty is entirely in deciding which roots are legitimate, and that decision depends on the index of the root.

Part (a) establishes the rule. A cube root is defined for every real number, because cubing a negative number returns a negative number: $(-2)^{3} = -8$, so $-2$ is a cube root of $-8$. A square root has no such property, because no real number squares to a negative value, so $x^{1/2}$ requires $x \ge 0$. The original expression uses only the cube root, so it is defined for all real $x$.

Part (c) cashes this in. The root $t = 4$ gives $x + 1 = 64$ and hence $x = 63$, while the root $t = -1$ gives $x + 1 = -1$ and hence $x = -2$. Both survive because the cube root accepts negative inputs, and both check correctly in the original equation.

Part (d) is the contrast that exposes the principle. If the same substitution is applied to $(x+1)^{1/2} - 3(x+1)^{1/4} - 4 = 0$ with $t = (x+1)^{1/4}$, the quadratic again yields $t = 4$ and $t = -1$. Now $t$ is a fourth root and must be non-negative, so $t = -1$ is impossible; the value $x = 0$ that it produces must be rejected, leaving only $x = 255$. The classic errors are rejecting $x = -2$ in part (c) by wrongly treating the cube root like a square root, accepting $x = 0$ in part (d), and forgetting to verify the candidate values in the original equation.
