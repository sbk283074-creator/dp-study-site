A discrete distribution given only as a bar chart of observed counts, so the heights must be normalised before the expected value and variance can be found

Mathematics: analysis and approaches HL · MATH-AHL4.7-501

Question

A random variable $X$ takes the values $0$, $1$, $2$, $3$ and $4$. The diagram shows the number of times each value was observed in a sample of 14 independent trials.

  1. [3 marks](a)

    Explain why the heights in the diagram cannot be used directly as the probabilities $P(X = k)$, and hence write down the value of $P(X = 0)$.

    (Explain)
  2. [3 marks](b)

    Find the expected value $E(X)$ of this distribution, giving your answer as an exact fraction.

    (Find)
  3. [4 marks](c)

    Find the variance $Var(X)$ of this distribution, giving your answer as an exact fraction.

    (Find)
  4. [3 marks](d)

    A game pays out $5X - 8$ in the same units. Find the expected payout, and state whether the game favours the player.

    (Find)

A random variable $X$ takes the values $0$, $1$, $2$, $3$ and $4$. The diagram shows the number of times each value was observed in a sample of 14 independent trials. (a) Explain why the heights in the diagram cannot be used directly as the probabilities $P(X = k)$, and hence write down the value of $P(X = 0)$. [3 marks] (Explain) (b) Find the expected value $E(X)$ of this distribution, giving your answer as an exact fraction. [3 marks] (Find) (c) Find the variance $Var(X)$ of this distribution, giving your answer as an exact fraction. [4 marks] (Find) (d) A game pays out $5X - 8$ in the same units. Find the expected payout, and state whether the game favours the player. [3 marks] (Find)
Reveal the answer

(a) The heights record how many observations fell on each value, so they are
frequencies rather than probabilities. Probabilities of a discrete distribution must be
non-negative and must sum to $1$, and these heights sum to

$$2 + 3 + 4 + 3 + 2 = 14,$$ (M1)

which is the sample size rather than $1$. (R1) Each height must therefore be divided by the
total of $14$ before it can be used as a probability:

$$P(X = 0) = \frac{2}{14} = \frac{1}{7}.$$ (A1)

The whole distribution is

$$P(X = 0) = \frac{1}{7}, \quad P(X = 1) = \frac{3}{14}, \quad P(X = 2) = \frac{2}{7},
\quad P(X = 3) = \frac{3}{14}, \quad P(X = 4) = \frac{1}{7},$$

and these five probabilities sum to $1$, which confirms the scaling was correct.

(b) The expected value is the sum of each value multiplied by its probability:

$$E(X) = \sum_{k=0}^{4} k \, P(X = k)
= \frac{0(2) + 1(3) + 2(4) + 3(3) + 4(2)}{14}.$$ (M1)(A1)

$$E(X) = \frac{0 + 3 + 8 + 9 + 8}{14} = \frac{28}{14} = 2.$$ (A1)

The distribution is symmetric about $2$, and the expected value is the centre of that symmetry,
which is a useful check on the arithmetic.

(c) The variance is most safely found from $E(X^{2}) - [E(X)]^{2}$. First compute

$$E(X^{2}) = \sum_{k=0}^{4} k^{2} P(X = k)
= \frac{0(2) + 1(3) + 4(4) + 9(3) + 16(2)}{14}.$$ (M1)(A1)

$$E(X^{2}) = \frac{0 + 3 + 16 + 27 + 32}{14} = \frac{78}{14} = \frac{39}{7}.$$ (A1)

Therefore

$$Var(X) = E(X^{2}) - [E(X)]^{2} = \frac{39}{7} - 2^{2} = \frac{39}{7} - \frac{28}{7}
= \frac{11}{7}.$$ (A1)

The variance is $\dfrac{11}{7} \approx 1.57$ (to three significant figures).

(d) The expectation of a linear function of a random variable is the same linear function of
the expectation, so

$$E(5X - 8) = 5E(X) - 8 = 5(2) - 8 = 2.$$ (M1)(A1)

The expected payout is $2$ per play. Because it is positive, the game favours the player:
on average a player gains $2$ for each play, and the operator loses that amount. (A1)

Note that the variance is not needed here. The linear rule for expectation does not require
independence and does not require the distribution to be known, only that $E(X)$ is known,
which is why part (b) is sufficient.

Markscheme notes

(a) (M1) for summing the heights to 14, (R1) for the explicit reason that probabilities must sum to 1 and these do not, (A1) for $P(X = 0) = \frac{1}{7}$ or an equivalent exact fraction or a decimal 0.143. Do not award the final mark for $\frac{2}{14}$ left unsimplified unless it is then used consistently. A student who writes $P(X = 0) = 2$ scores (M1)(R0)(A0). (b) (M1) for the weighted sum structure, (A1) for the correct numerator 28, (A1) for 2. Follow-through from an incorrect normalisation in (a) is allowed only if every probability used is consistent with that normalisation. (c) (M1) for computing $E(X^{2})$ with squared values, (A1) for the numerator 78, (A1) for $\frac{39}{7}$, (A1) for $\frac{11}{7}$ or 1.57. Award (A0) for the last mark if the variance is negative, which indicates the two terms were subtracted in the wrong order. (d) (M1) for using $E(aX + b) = aE(X) + b$, (A1) for $2$, (A1) for the conclusion that the game favours the player because the expected payout is positive. Accept a correct conclusion drawn from a follow-through value in (b).

Why this question is hard

This item tests a single idea that is easy to state and easy to violate: a bar chart
of a distribution may be drawn in counts or in probabilities, and the two are not
interchangeable. Every routine exercise in the syllabus presents the probabilities directly,
so the habit a student has built is to read a height off the chart and use it. Here the heights
are counts from a sample of 14 trials, and the first thing that should be noticed is that they
sum to 14. A probability distribution cannot do that. The scaling factor is the sample size,
and once each height is divided by 14 the five probabilities sum to 1, which is the check that
the normalisation is right.

The cost of missing this is large and systematic rather than small. If the heights are used
directly, the "expected value" is $0(2) + 1(3) + 2(4) + 3(3) + 4(2) = 28$, which is 14 times the
correct answer of 2, and the variance is inflated by a factor of $14^{2}$ as well. Both answers
are self-consistent with the wrong normalisation, so nothing in the arithmetic flags the error;
the only warning is the sum of the probabilities. That is what makes the item worth asking: the
mistake is not detectable downstream.

Part (b) is deliberately the easy part once the distribution is correct, because the
distribution is symmetric about 2 and the expected value is the centre of symmetry. The
symmetric shape also gives a free check on the answer, and a student who obtains something
other than 2 should be suspicious.

Part (c) carries the second demand. The variance must be obtained from $E(X^{2}) - [E(X)]^{2}$,
which requires squaring each value before weighting it, and the arithmetic stays in exact
fractions: $E(X^{2}) = \frac{39}{7}$ and the variance is $\frac{11}{7}$. A student who instead
averages the squared deviations about the mean will reach the same value but has more chances
to make an arithmetic slip, and one who subtracts in the wrong order obtains a negative
variance, which is impossible and should be caught.

Part (d) is a judgement rather than a calculation. The expected payout is $2$, and the
question is whether that favours the player; because it is positive it does, and the answer has
to say so. The point worth noticing is that the variance is not needed at all: the expectation
of a linear function depends only on the expectation of the variable, so no assumption about
independence or about the shape of the distribution is required. A student who computes the
variance of the payout and reports it as the answer has answered a different question.

Challenge lever
The five heights in the diagram are counts of observations, and they add to 14 rather than to 1, so they are not probabilities. The first move a prepared student makes is to read a height off the chart and treat it as P(X = k), because every textbook exercise presents a bar chart of a probability distribution whose heights already sum to one. Here the sum is 14, so every probability is wrong by a factor of 14 and both the expected value and the variance are inflated. The correct route is to divide each height by the total first, and only then apply the standard formulae; the second demand is that the variance must be computed from E(X^2) - [E(X)]^2 rather than from a spread-sheet of the values, which keeps the arithmetic in exact fractions.
