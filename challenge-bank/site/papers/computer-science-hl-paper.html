PulseTrack - steady-run detection

PulseTrack is a wearable heart-rate monitor. It samples the wearer's heart rate once per second and stores each day's readings as a list of integers.

For every reading the device reports the length of the steady run ending at that reading: the number of immediately preceding readings such that every step between consecutive readings in that run differs by no more than a tolerance of 5 beats per minute. A reading with no steady predecessor has run length 0. So for the series [70, 72, 71, 90, 89, 88, 87] the run lengths are [0, 1, 2, 0, 1, 2, 3].

A developer wrote the function below and claims it runs in linear time: "the while loop stops as soon as it reaches a reading that differs from the one before it by more than the tolerance, and in a real recording that happens after a step or two."

The device records 86,400 readings per day, one per second for 24 hours, and runs the analysis each night on the day's readings. The analysis must finish within a few seconds.

def steady_runs(readings, tol=5):
    runs = []
    for i in range(len(readings)):
        count = 0
        j = i
        while j > 0 and abs(readings[j] - readings[j - 1]) <= tol:
            count += 1
            j -= 1
        runs.append(count)
    return runs

The readings are stored as a list of integers, one per second. The nightly analysis must finish in a few seconds on the device, and it must report the run lengths exactly.

    (Explain)
  2. [4 marks](b)

The team writes its unit tests against a small matrix of the same density, and then deploys the same code against the production matrix. The table gives the two matrices. Every entry is held as an 8-byte floating-point number, and the deployment target is a server with 64 GB of memory.

A sparse matrix is held in a dense two-dimensional array, and the same code is used for the unit tests and for production. The matrix, the two scales and the cost of one entry are given in the table. Answer all parts using the figures in the table.

  1. [3 marks](a)

    Calculate the number of entries a dense two-dimensional array stores for each of the two matrices, and state the memory each array occupies in bytes and in gigabytes.

    (Calculate)
  2. [3 marks](b)

    Calculate the memory a sparse representation requires if each non-zero entry is stored as an 8-byte value together with a 4-byte row index and a 4-byte column index, and express the result for the production matrix in megabytes.

    (Calculate)
  3. [4 marks](c)

    Determine the number of floating-point operations one matrix-vector product performs on the production matrix under each representation, state the time each takes if the processor performs 10^9 operations per second, and hence determine the ratio of the two.

    (Determine)
  4. [2 marks](d)

    Explain why the unit tests give no warning of the problem, and state one property of the data that a designer must check before choosing between the two representations.

    (Explain)
