# The World's Wife — English Lit Lab

An interactive study site for Carol Ann Duffy's poetry collection *The World's Wife* (1999).

All 30 poems are registered in a single-page reader (`index.html`): each entry has the poem
text, quote-accurate key-passage annotations, a vocabulary list, and a deep analysis (context,
speaker/voice, themes, poetic devices, structure, IB-essay usage, examiner-style questions).

## Run locally

Just open `index.html` in a browser — no build step, no dependencies.

## Deploy

This is a static site. To publish it with GitHub Pages:

1. Push the repo to GitHub.
2. In the repo's **Settings → Pages**, set the source to the `main` branch, root (`/`).
3. Visit `https://<user>.github.io/<repo>/`.

> Note: only `index.html`, `README.md`, and `.gitignore` are tracked. The `.workbuddy/`
> folder (assistant memory) and the source `.docx` poem files are intentionally git-ignored.
