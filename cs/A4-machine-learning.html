A4 · Machine learning

Traditional programming is you writing the rules and the computer applying them. Machine learning inverts that: you supply the data and the answers, and the computer works out the rules. That inversion is one of the most important ideas in modern computing, and it is new to this syllabus — which means the questions are still settling into a pattern, but the conceptual core is stable: what a model is, how it learns, how you know whether it learned anything, and what happens when it is wrong.

Theme A · examined in Paper 1 (and frequently in the case study) A4.1 Fundamentals · A4.4 Ethical considerations HL only: A4.2 Data preprocessing · A4.3 Machine learning approaches
Why the IBO added this topic

The stated aim of the new course is that it should be "future-facing" and about computer science rather than information technology. Machine learning is the clearest case where knowing the computing matters more than knowing the software: you cannot evaluate a system that diagnoses patients, shortlists job applicants or prices insurance unless you understand what the model was trained on, what it optimised, and how it can fail. That is exactly what Paper 1 will ask you to do — and notice that almost every question is analysis, not code.

A4.1 · What machine learning actually is

Here is the inversion, stated precisely.

Traditional programmingMachine learning
Input to the machineRules + dataData + answers
Output from the machineAnswersRules (a model)
Who writes the rulesYouThe learning algorithm
ExampleYou code "if the message contains 'free iPad' then spam"You show the system 10 000 messages labelled spam or not, and it finds patterns you never wrote down
Works well whenYou can articulate the rule exactlyThe rule exists but you cannot state it — recognising a face, translating a sentence, predicting demand
Trap — "the computer learns like a human"

It does not, and saying so loses marks. What happens is narrowly this: the system has a large set of adjustable numbers (parameters/weights) and a fixed procedure that adjusts them slightly to reduce a number called the loss (a measure of how wrong its outputs are on the training data). Repeat that adjustment many times and the parameters end up at values that perform well on the data seen. There is no understanding, no intention and no generalisation beyond what the data supports. The correct phrase is "the model is fitted to the data" or "the parameters are optimised", not "the model understands".

The three types of learning

Supervised learning

The training data is labelled: every example comes with the correct answer. The model learns to map input to that answer.

Classification — the label is a category: is this email spam, is this tumour malignant, which digit is this?

Regression — the label is a number: what will this house sell for, how many units will we sell next week, what will the temperature be?

Everyday example: a photo app that has been shown thousands of pictures labelled "cat" or "not cat" and now labels new photos.

Unsupervised learning

The training data is unlabelled. There is no right answer to learn; the model is asked to find structure — usually to group similar examples together (clustering) or to describe the data with fewer numbers (dimensionality reduction).

Everyday example: a music service noticing that you and 40 000 other listeners play the same obscure tracks, and building a "you might like" group — nobody told it the genre existed.

Reinforcement learning

There is no dataset at all. An agent acts in an environment and receives a reward signal; it learns a policy (what to do in each state) that maximises total reward over time. It learns by trial and error, including from rewards that arrive much later than the action that earned them.

Everyday example: a program that learns to play a game by playing it millions of times, receiving +1 for a win and −1 for a loss, with no human ever showing it a good move.

How to use it — choosing the type from a scenario
  1. Do you have historical examples with the correct answer? If yes → supervised.
  2. Is the answer a category or a quantity? Category → classification. Quantity → regression.
  3. No correct answers, but you want groups or structure? → unsupervised (clustering).
  4. No data at all, but there is an environment the system can act in and a score it can receive? → reinforcement learning.
  5. Say which one the scenario implies and why — the "why" is the mark.

A4.2 · Data preprocessing and the workflow HL only

  1. Collect data. More relevant data beats a cleverer algorithm, almost always. But data collection is where bias enters: if you collect only from one group, the model only works for that group.
  2. Clean it (A4.2, HL). Real data has missing values, duplicates, impossible values, inconsistent spellings and units, and outliers. You must handle missing data (drop the row, or impute a value such as the mean), remove duplicates, and decide whether an outlier is an error or a genuine extreme that matters.
  3. Select and engineer features. A feature is an input variable the model uses. Selecting the right ones is often more valuable than choosing a fancier model; irrelevant features add noise, and too many features relative to the number of examples makes overfitting far more likely.
  4. Split the data into training, validation and test sets.
  5. Train the model on the training set — this is where the parameters are adjusted.
  6. Tune using the validation set — choose the settings that are not learned from data (hyperparameters, such as k in k-nearest neighbours or the number of layers) by seeing how each performs on data the model has not trained on.
  7. Evaluate once on the test set, which has been kept sealed until now, to estimate how the model will do in the real world.
  8. Deploy and monitor. A model's performance decays as the world changes (model drift), so it must be retrained.
Why Why you must split the data — overfitting and underfitting, and why the test set must be sealed
  1. The purpose of a model is not to do well on data it has seen; it is to do well on data it has not seen. That property is called generalisation, and it is the only thing we care about.
  2. Accuracy on the training set is therefore a meaningless measure of quality. A model with enough parameters can memorise the training set perfectly — including its noise and its errors — and be worthless on anything new. That is overfitting (): the model has fitted the training data too closely.
  3. The opposite failure is underfitting (): the model is too simple to capture the pattern at all, so it does badly on both training and test data.
  4. So we hold data back. If the model has never seen that data, its performance there is an honest estimate of generalisation.
  5. Why three sets and not two? Because choosing hyperparameters on the test set is itself a form of learning from it — you would be selecting the settings that happen to suit that particular sample. The validation set absorbs that selection pressure, leaving the test set genuinely untouched for a single final estimate. Using the test set to tune is the most common methodological error and it invalidates your result.
  6. Practical splits: 60/20/20 or 70/15/15 for training/validation/test; and split randomly, or by time if the data is a time series (you must not train on the future to predict the past).

What it means: a training accuracy of 99 % and a test accuracy of 62 % is not a good model — it is an overfitted one, and the gap between the two numbers is the diagnostic.

Key concepts, defined

Feature ()
An input variable the model uses to make its prediction. In a house-price model: floor area, number of bedrooms, distance to the station.
Label ()
The correct answer for a training example — the thing the model is being taught to predict.
Weight / parameter ( / )
An adjustable number inside the model that determines how much influence a feature has. Training is the process of finding good weights.
Training ()
Adjusting the weights to reduce the error on the training data.
Inference ()
Using the trained model to make a prediction. Expensive once, cheap forever after — and, crucially, the weights are frozen.
Loss / cost function ()
A single number measuring how wrong the model's predictions are. Training is optimisation of this number.
Hyperparameter ()
A setting chosen by the designer rather than learned from data: the learning rate, k in k-NN, the number of layers, the number of training rounds.
Epoch
One complete pass through the training data.
Accuracy
Proportion of all predictions that were correct. Dangerous on its own — see below.
Precision and recall
Precision: of the things the model flagged, how many were actually positive. Recall: of the things that actually were positive, how many did the model catch. They trade off against each other, and which you prefer depends on the cost of each kind of mistake.
Confusion matrix
A two-by-two table of true positives, false positives, false negatives and true negatives. It is the source from which precision, recall and accuracy are all computed.
Why accuracy is a trap

Suppose 1 in 1000 transactions is fraudulent. A model that predicts "never fraudulent" for everything scores 99.9 % accuracy and is completely useless — it catches no fraud at all. Accuracy hides this because the classes are extremely imbalanced. That is why you look at the confusion matrix instead: how many of the actual frauds did we catch (recall), and when we blocked a card how often were we right (precision)? For a rare but serious class — disease, fraud, structural fault — recall is usually the one you care about, because a missed case is far more costly than a false alarm. Say that reasoning out loud in your answer; it is the difference between a definition and an evaluation.

Worked example 1 IB-style · 8 marks · confusion matrix, accuracy, precision, recall

Question. A model screens 1000 patients for a disease. 60 patients have the disease. The model flags 70 patients as positive, of whom 55 really do have it. (a) Complete the confusion matrix. (b) Calculate accuracy, precision and recall. (c) The model is to be used to decide who gets an invasive follow-up test. Comment on whether accuracy is a suitable measure here.

  1. True positives (TP) = 55 — flagged and ill.
  2. False positives (FP) = 70 − 55 = 15 — flagged but healthy.
  3. False negatives (FN) = 60 − 55 = 5 — ill but missed.
  4. True negatives (TN) = 1000 − 55 − 15 − 5 = 925 — healthy and not flagged.
  5. Accuracy = (TP + TN) / total = (55 + 925) / 1000 = 0.980 = 98.0 %.
  6. Precision = TP / (TP + FP) = 55 / 70 = 0.786 = 78.6 %.
  7. Recall = TP / (TP + FN) = 55 / 60 = 0.917 = 91.7 %.
  8. (c) Accuracy is misleading here. A model that flagged nobody at all would score 94 % accuracy (940/1000) while detecting no disease whatsoever, because the disease is rare — only 6 % of the sample.
  9. For an invasive follow-up, both errors matter: a false negative means a sick patient is not treated (so recall matters), and a false positive means a healthy patient undergoes an invasive procedure (so precision matters). The right answer is to report precision, recall and the trade-off between them, not accuracy.
Marks: 1 each for TP, FP, FN, TN; 1 each for accuracy, precision, recall; 1–2 for the comment on accuracy being unsuitable because the classes are imbalanced and because the two error types have very different costs.

A4.3 · Machine learning approaches: k-nearest neighbours HL only

k-NN is the algorithm to study because you can do it entirely by hand, so the exam can ask you to. The idea is almost insultingly simple: to classify a new point, find the k training points closest to it and take a majority vote.

How to use it — the procedure
  1. Choose k (an odd number avoids ties in binary classification).
  2. Compute the distance from the new point to every training point, usually Euclidean: \(d = \sqrt{(x_1 - a_1)^2 + (x_2 - a_2)^2}\).
  3. Sort the distances and take the k smallest.
  4. Count the labels among those k neighbours and assign the majority label.
  5. For regression instead of classification, take the mean of the k neighbours' values rather than a vote.
Worked example 2 IB-style · 9 marks · k-NN by hand, k = 3

Question. A college records, for each of six former students, the hours studied (x) and the number of past papers completed (y), and whether they passed. A current student has studied 6 hours and completed 4 past papers. Use k-NN with k = 3 to predict whether they pass.

Student x (hours) y (papers) Result
A 2 1 Fail
B 3 2 Fail
C 3 1 Fail
D 7 5 Pass
E 8 6 Pass
F 7 6 Pass
Query Q 6 4 ?
  1. Compute \(d = \sqrt{(6-x)^2 + (4-y)^2}\) to every point.
  2. A: \(\sqrt{4^2 + 3^2} = \sqrt{16+9} = \sqrt{25} = \mathbf{5.000}\)
  3. B: \(\sqrt{3^2 + 2^2} = \sqrt{9+4} = \sqrt{13} \approx \mathbf{3.606}\)
  4. C: \(\sqrt{3^2 + 3^2} = \sqrt{18} \approx \mathbf{4.243}\)
  5. D: \(\sqrt{1^2 + 1^2} = \sqrt{2} \approx \mathbf{1.414}\)
  6. E: \(\sqrt{2^2 + 2^2} = \sqrt{8} \approx \mathbf{2.828}\)
  7. F: \(\sqrt{1^2 + 2^2} = \sqrt{5} \approx \mathbf{2.236}\)
  8. Sort: D (1.414) < F (2.236) < E (2.828) < B (3.606) < C (4.243) < A (5.000).
  9. The three nearest are D, F and E — all labelled Pass. Majority vote: Pass.
Answer: Pass, with all three nearest neighbours agreeing. Marks: 1 for the formula, up to 4 for correct distances, 1 for identifying the three nearest, 1 for the vote, 1–2 for a sensible comment (below).

The comment that earns the last two marks: with k = 1 the prediction would also be Pass but it would depend entirely on a single individual, so it is very sensitive to noise and to one unusual student. With k = 5, the neighbours would be D, F, E, B (Fail) and C (Fail) — still a 3-to-2 majority for Pass, but a much less confident one. Small k gives a flexible, high-variance model that fits the training data closely; large k gives a smoother, lower-variance model that can miss genuine structure. Choosing k is exactly the overfitting/underfitting trade-off of Figure 1, and it is chosen on the validation set.

Why Why feature scaling is not optional in k-NN
  1. Suppose one feature is annual income in yuan (range 0 to 500 000) and the other is age (range 18 to 65).
  2. The squared difference in income will be on the order of \(10^{10}\) while the squared difference in age is at most about 2200. The distance is therefore almost entirely determined by income, and age contributes essentially nothing.
  3. The model has silently ignored a feature, and you get no warning.
  4. The fix is normalisation (scaling each feature to 0–1) or standardisation (subtract the mean, divide by the standard deviation, so each feature has mean 0 and standard deviation 1).
  5. After scaling, both features contribute on comparable terms. The same issue affects any distance- or gradient-based method, which is most of machine learning.

What it means: preprocessing is not admin; it changes what the model can see. When it matters less: tree-based methods split one feature at a time, so they are largely indifferent to scale.

A4.3 · Machine learning approaches: neural networks HL only

A neural network is a stack of layers of simple units. Each unit takes a weighted sum of its inputs, adds a bias, and passes the result through a non-linear activation function. Stack enough of them and the whole thing can approximate extraordinarily complicated relationships between input and output.

PartWhat it is
Input layerOne unit per feature. It performs no computation; it just presents the values.
Hidden layer(s)Layers between input and output. This is where the computation happens, and "deep learning" simply means many hidden layers.
Output layerProduces the answer: one unit for regression or binary classification, several (often with softmax) for multi-class classification.
WeightsOne per connection. They are what training adjusts, and they are what the model is.
BiasAn extra adjustable constant added to the weighted sum, letting a unit fire even when all inputs are zero.
Activation functionA non-linear function applied to the weighted sum. Common choices: sigmoid, tanh, ReLU.
Why Why an activation function must be non-linear — the collapse argument
  1. Each unit computes a weighted sum of its inputs — a linear operation.
  2. A linear function of a linear function is still linear. So if the activation were linear (or absent), a hundred-layer network would mathematically collapse into a single linear function of the inputs.
  3. That network could only ever draw a straight line (or a flat plane) as its decision boundary — no more powerful than the simplest possible model, no matter how many layers you stacked.
  4. Inserting a non-linearity after each sum breaks the collapse. Each layer can now bend the function a little, and many layers bend it enough to represent very complex boundaries.
  5. ReLU (\(f(x) = \max(0, x)\)) is the standard modern choice because it is cheap to compute and its gradient does not vanish for positive values, which makes deep networks trainable. The sigmoid squashes any input into (0, 1), which is why it is used for outputs that must be interpreted as a probability — but it saturates at the extremes, so its gradient becomes tiny and learning slows, which is why it is rarely used in hidden layers today.

What it means: the non-linearity is not a detail; it is the entire source of a neural network's expressive power.

Worked example 3 IB-style · 8 marks · a full forward pass by hand

Question. A network has two inputs, a hidden layer of two units with the sigmoid activation \(\sigma(z)=\dfrac{1}{1+e^{-z}}\), and one output unit with the sigmoid activation. Inputs are \(x_1 = 0.5,\ x_2 = 0.8\). Weights and biases are given below. Compute the output and state the predicted class using a threshold of 0.5.

hidden unit 1: w = (0.4, -0.2) bias = 0.1
hidden unit 2: w = (-0.5, 0.7) bias = -0.3
output unit : w = (0.9, -0.6) bias = 0.2
  1. Hidden unit 1. Weighted sum: \(z_1 = 0.4(0.5) + (-0.2)(0.8) + 0.1 = 0.20 - 0.16 + 0.10 = 0.14\).
  2. Activate: \(h_1 = \sigma(0.14) = \dfrac{1}{1+e^{-0.14}} = \dfrac{1}{1+0.8694} = \mathbf{0.535}\) (3 s.f.).
  3. Hidden unit 2. \(z_2 = (-0.5)(0.5) + 0.7(0.8) + (-0.3) = -0.25 + 0.56 - 0.30 = 0.01\).
  4. Activate: \(h_2 = \sigma(0.01) = \dfrac{1}{1+0.9900} = \mathbf{0.503}\) (3 s.f.).
  5. Output unit. Its inputs are now \(h_1\) and \(h_2\): \(z_o = 0.9(0.535) + (-0.6)(0.503) + 0.2 = 0.4815 - 0.3015 + 0.2 = 0.380\).
  6. Activate: \(y = \sigma(0.380) = \dfrac{1}{1+e^{-0.380}} = \dfrac{1}{1+0.6839} = \mathbf{0.594}\) (3 s.f.).
  7. Threshold 0.5: since 0.594 > 0.5, the predicted class is 1 (positive).
  8. Interpretation: 0.594 is a probability-like score, not a certainty. It is only just above the threshold, so this is a low-confidence prediction — worth stating, because a question often asks what the value means.
Answer: h₁ = 0.535, h₂ = 0.503, output = 0.594 → class 1. Marks: 1 per correct weighted sum, 1 per correct activation, 1 for the threshold decision, 1 for interpreting the value as a confidence. The most common arithmetic slip is forgetting to add the bias — check for it.
Exam technique — what the exam will and will not ask you to do

You will not be asked to implement backpropagation or to derive a gradient. You will be asked to: identify the layers and say what each does; explain what a weight is; perform a forward pass with given weights (as above); explain the role of the activation function; explain why training needs many examples and much computation; and explain why the model's decisions are hard to explain. Practise the forward-pass arithmetic until it is mechanical — it is the one place in this topic where a numerical answer is unambiguously right or wrong.

A4.4 · Limitations and ethics

This is the part of A4 that is examined hardest, because it is where machine learning meets the social and ethical reasoning the IB cares about. Each issue below has a mechanism — learn the mechanism, not just the slogan.

Bias and discrimination ()

Mechanism: the model learns whatever regularities exist in the training data, including the ones produced by historical prejudice. If a company hired mostly men for a decade, a model trained on those decisions learns that being male predicts being hired. The model is not prejudiced; it is accurately reproducing a prejudiced process — which is worse, because it does so at scale, automatically, and with the appearance of objectivity. Also: under-representation means the model simply has fewer examples for some groups, so it performs worse for them. Removing the protected attribute does not fix it, because other features correlate with it (postcode correlates with ethnicity).

Lack of explainability ()

Mechanism: a large model's decision is the combined effect of millions of weights, none of which corresponds to a human-understandable rule. So the model can be right without anyone being able to say why. This matters legally (data-protection regimes in many jurisdictions grant a right to an explanation for automated decisions) and practically (if you cannot explain a diagnosis, a doctor cannot verify it, and a developer cannot debug it). The field of explainable AI exists because this is a real barrier to deploying models in high-stakes settings.

Privacy ()

Mechanism: models are trained on personal data, and they can leak it — a model trained on medical records may reproduce details of individuals when prompted, an attack called membership inference or model inversion. Consent is also weak: data collected for one purpose is routinely reused for training without a fresh decision by the subject. Techniques such as differential privacy (adding carefully calibrated noise so no individual's data materially affects the output) and federated learning (train on the device, share only the updates) exist and are worth naming.

Environmental cost ()

Mechanism: training a large model means running thousands of power-hungry processors for weeks, consuming electricity and the water used to cool the data centres. There is also the hardware's embodied carbon. The honest observation is that inference now dominates total energy use for widely deployed models, because a model is trained once and used billions of times — so the environmental argument is about deployment scale as much as training runs.

Deepfakes and misinformation ()

Mechanism: generative models can produce photorealistic images, video and audio of people saying and doing things they never did. The damage is not only individual (fraud, revenge, political manipulation) but epistemic: when convincing fakes are cheap, people can dismiss genuine evidence as fake — a phenomenon sometimes called the "liar's dividend". Detection is an arms race, so the durable responses are provenance (cryptographic signing of authentic media) and literacy, not detection alone.

Job displacement and accountability ()

Mechanism: machine learning automates tasks rather than whole jobs, but the tasks it automates first are the routine cognitive ones that have historically been entry-level professional work. The distributional effect matters: productivity gains accrue to the owners of the system while displacement costs fall on individuals. And accountability is genuinely hard: when a model's decision harms someone, the chain from the data collector to the trainer to the deployer to the user makes it easy for everyone to disclaim responsibility. "The algorithm decided" is not an answer the law accepts.

How to write the ML evaluation — the structure that scores
  1. Say what kind of system this is and what it optimises. "This is a supervised classification system trained on historical hiring decisions, so it optimises accuracy against those past decisions."
  2. Name the stakeholders — applicants, the employer, existing staff, regulators, and groups historically under-represented in the industry.
  3. Develop two benefits concretely: consistency (the same application always gets the same treatment, unlike a tired human at 5 pm), and throughput (thousands of applications screened cheaply).
  4. Develop two harms concretely, with the mechanism: historical bias in the training labels is learned and amplified; and unsuccessful applicants cannot be told why they were rejected, so they cannot appeal or improve.
  5. Propose mitigations: audit the model's outcomes for disparate impact across groups before deployment; keep a human in the loop for decisions that affect individuals; publish the features used; retrain and re-audit on a schedule.
  6. Reach a judgement: "acceptable as a screening aid with a human decision and regular auditing; not acceptable as an autonomous reject mechanism, because the harms are concentrated on individuals who have no route to challenge the outcome."

The single sentence that most improves these answers is one that distinguishes what the model was optimised for from what we actually want. A model optimises the loss function you gave it; everything you forgot to put in that function is something it will happily sacrifice.

Practice

  1. Explain the difference between supervised and unsupervised learning, giving an example of each.

    Show answer

    In supervised learning the training data is labelled: each example comes with the correct answer, and the model learns to map input to that answer. Example: a system shown thousands of X-rays each labelled "fracture" or "no fracture", which then classifies new X-rays.

    In unsupervised learning the data has no labels; the model is asked to find structure, typically by grouping similar examples. Example: a retailer feeding purchase histories into a clustering algorithm and discovering four distinct customer groups it had never defined.

    The distinguishing feature is the presence or absence of the correct answer in the training data — say that explicitly.

  2. A model predicts whether a machine will fail in the next month. Explain why training accuracy alone is not a sufficient measure of whether the model is useful.

    Show answer
    1. Training accuracy measures performance on data the model has already seen, and a model with enough capacity can memorise that data — including its noise — without learning anything general.
    2. That is overfitting, and it produces high training accuracy with poor performance on new data, which is the only performance that matters.
    3. The correct procedure is to hold back a validation and a test set, train only on the training set, and measure on data the model has never seen.
    4. Additionally, failures are usually rare, so accuracy is dominated by the majority class; precision, recall and the confusion matrix are needed to see whether the model actually catches the failures.

  3. Using the six-student dataset from Worked example 2, predict the result for a student who studied 4 hours and completed 2 past papers, using k = 3. Show all distances.

    Show answer
    1. Query Q = (4, 2). Distance \(d=\sqrt{(4-x)^2+(2-y)^2}\).
    2. A (2,1): \(\sqrt{4+1}=\sqrt5\approx2.236\). B (3,2): \(\sqrt{1+0}=1.000\). C (3,1): \(\sqrt{1+1}=\sqrt2\approx1.414\). D (7,5): \(\sqrt{9+9}=\sqrt{18}\approx4.243\). E (8,6): \(\sqrt{16+16}=\sqrt{32}\approx5.657\). F (7,6): \(\sqrt{9+16}=5.000\).
    3. Three nearest: B (1.000, Fail), C (1.414, Fail), A (2.236, Fail).
    4. All three are Fail, so the prediction is Fail — and with unanimous neighbours this is a confident prediction.
    Answer: Fail. Note how the same dataset gives Pass for (6,4) and Fail for (4,2) — the decision boundary is a curve in the 2-D feature space, which is precisely what nearest-neighbour methods produce.

  4. Explain why the value of k in k-nearest neighbours is described as a trade-off, and say how you would choose it.

    Show answer
    1. A small k (such as 1) makes the model very flexible: the decision boundary follows individual training points closely, so it fits the training data well but is highly sensitive to noise and outliers — high variance, overfitting.
    2. A large k smooths the boundary by averaging over many neighbours, which reduces sensitivity to noise but can wash out genuine local structure — high bias, underfitting.
    3. So the choice is exactly the bias–variance trade-off, the same one shown in Figure 1.
    4. Choose it empirically: try several values, measure each one's accuracy (or error) on the validation set, and pick the value that performs best there. Confirm once on the test set.
    Trap: choosing k by looking at the test set. That contaminates the test set and invalidates your final estimate.

  5. A spam filter flags 200 of 10 000 emails as spam; 160 of those really are spam, and 40 real spam emails were missed. Calculate precision and recall, and state which one matters more for this application, with a reason.

    Show answer
    1. TP = 160, FP = 40. Total actual spam = 160 + 40 = 200, so FN = 40.
    2. Precision = TP / (TP + FP) = 160 / 200 = 0.80.
    3. Recall = TP / (TP + FN) = 160 / 200 = 0.80.
    4. For a spam filter, precision matters more: a false positive means a genuine email — a job offer, a password reset, a message from a family member — is hidden from the user and may never be seen, whereas a false negative merely means the user deletes one more junk email themselves.
    5. The two errors have very unequal costs, and that asymmetry, not the numbers, decides which metric to optimise.

  6. Explain what is meant by the activation function of a neuron, and explain why a network without one would be no more powerful than a single-layer model.

    Show answer
    1. Each unit computes the weighted sum of its inputs plus a bias, and then applies the activation function to produce the unit's output.
    2. A weighted sum is a linear operation, and composing linear operations gives another linear operation.
    3. So without a non-linear activation, no matter how many layers you stack, the whole network reduces mathematically to one linear function of the inputs — it could only ever produce a straight-line decision boundary.
    4. Applying a non-linear function at each layer breaks that collapse: each layer can bend the mapping, and many layers together can represent very complex functions. That is the source of a network's expressive power.

  7. Discuss the use of a machine-learning system to predict which students are at risk of failing, so that teachers can intervene.

    Show answer
    1. Stakeholders: the students flagged, the students not flagged, teachers, parents, the school, and the education authority.
    2. Benefits: support can be targeted at the students who need it earliest, when intervention is cheapest and most effective; teachers' limited time is allocated better; and patterns a human would miss across hundreds of students (falling attendance combined with a particular assessment profile) can be surfaced.
    3. Harms — with mechanisms: the model is trained on past outcomes, so it will learn whatever disadvantages existed historically; students from groups already over-represented among past failures will be flagged disproportionately, and being labelled "at risk" can lower expectations and become self-fulfilling. Data on family income, health and behaviour is highly sensitive and its use may exceed what students consented to. And the prediction is probabilistic, so some flagged students were never at risk while some who were at risk are missed and get no help.
    4. Mitigations: audit false-positive and false-negative rates across groups; use the output only to offer support, never to withdraw it; tell students what data is used; keep the decision with a teacher who knows the student; review the model each year.
    5. Judgement: defensible as a prompt for a human conversation about support, provided it is audited and transparent; not defensible as an autonomous allocation of teaching time, because the cost of a wrong prediction falls on an individual child with no route to challenge it.
    Marks: stakeholders; developed benefits; developed harms with mechanism; mitigations; a clear judgement. A conclusion that says "it depends" without saying what it depends on is not a judgement.

  8. A training run gives 99 % accuracy on the training set and 61 % on the validation set. Identify the problem, explain what has happened, and suggest two ways to improve generalisation.

    Show answer
    1. This is overfitting: the model has fitted the training data, including its noise, rather than the underlying pattern, so it does not generalise.
    2. The large gap between the two figures is the diagnostic — training accuracy alone would have looked excellent.
    3. Improve by (any two of): collecting more training data; simplifying the model (fewer features, fewer parameters, fewer layers); regularisation, which penalises large weights and so discourages the model from contorting itself to fit individual points; early stopping — stop training when validation error stops improving, as in Figure 1; or data augmentation, which creates additional plausible training examples.
    4. Also worth a mark: check for data leakage, where information about the test set has accidentally entered training — that produces the same symptom.
